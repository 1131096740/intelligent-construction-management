# 项目垫资到账与实付差额

仅适用于已经完整安装任务 16 登记实付款、任务 24 转款容量围栏、任务 25 现金保管规则和任务 30 凭证查询授权的第 267 条迁移后继环境。按批准的受限运行角色设置 `jg.task16_runtime_role`，在同一事务安装本目录 SQL。旧付款准备文件及历史环境资格保持原样。

新增三张事实表，对运行角色只授予读取和插入，且依旧没有经营事实表的直接写权限。新自有本金银行候选通过精确函数查询，银行认领原表的权限不扩大。两个延期守卫分别核对差额事实与该笔首次实付的分摊，以及拒绝无确认为原项目款和待归属批次混填的同公司实付。未安装此文件的环境不得启用项目垫资差额。
