# 公共现金与公司资金转款安装顺序

转款复用任务 16 已安装的实付资金表及原账户写入角色。历史任务 16 材料保留原字节。部署候选须先核对正式实付安装及任务 24 前向迁移，再在显式选择既有实付运行角色的所有者事务内执行 `registered-fund-transfer-payment-fence.sql`。

已装实付的数据库先执行迁移，迁移会安装分摊上的转款容量约束。全新隔离数据库可先执行迁移，再执行任务 16 原安装和本文件。本文件同时适用两种顺序，它核对已存在的约束或添加缺失约束，并仅为指定的低权限实付角色补齐转款所需列、行权限。任何转款写入均检查实付分摊容量触发器处于启用状态。运行角色、禁用或内容不同的同名触发器核验失败时，应停止并保留原状态。

本地受限验证入口使用 `run-task398-shared-standard-local.cjs --transfer-real`。它只消费独占 PostgreSQL 16、本地合成数据和当前提交准确迁移清单。
