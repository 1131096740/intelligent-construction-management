# A07 三份简版合同母版

合同部已审核通过材料采购、设备租赁和劳务分包三份 Word。三个 `*-approved.docx` 保存送审通过的原始字节。与受控的任务 08 简版相比，只增加两行甲乙方名称。

对应的 `*-a4-ready.docx` 是系统使用的兼容版。材料采购原本已设置 A4，设备租赁和劳务分包补 A4 纵向页尺寸。三份兼容版均清理了缺失设置文件的内部引用，为已存在的字体和样式部件补齐内容类型声明。其余 XML、正文和样式文件逐项核对。隔离应用经过正式接口完成版式预览、发布和实际 Word/PDF 下载。

文件来源、文件摘要和预览验收见 [#426 记录](../../../../../docs/progress/2026-11-25-issue-426.md)。正式环境的版式发布通过合同部有权限的正常工作台办理。
