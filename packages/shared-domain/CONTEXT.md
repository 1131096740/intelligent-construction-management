# 项目经营共享领域词汇

本文件只定义 API、Web 管理端和跨端契约共同使用的业务词汇。完整规则以 [`项目经营总账、施工企业经营接管与统一业务录入正式规格`](../../docs/specs/2026-08-12-project-operating-ledger-construction-enterprise-takeover-unified-entry.md) 为准。

## 参与主体

**项目**：项目经营核算和管理的归集维度，不是合同签约、收款或付款的法律主体。

**业主**：项目上游合同、结算和付款的相对方。

**施工企业**：与业主签订对上合同、接收业主付款，并可能与我方公司或下游签约和付款的实际企业。用户界面不得用“挂靠企业”替代本词。

**我方公司**：纳入项目经营管理、可以接收施工企业拨款、支付下游、为项目垫资或承担盈亏分配的我方法人主体。

**参与公司**：已经在某项目发生合同、结算、资金、垫资或盈亏分配事实的具体我方公司。

**下游相对方**：向项目提供材料、施工、专业分包、机械租赁或其他服务的供应商、班组、单位或企业。

## 账与事实

**经营事实**：已经实际发生或经过业务确认，能够影响项目经营、主体往来或资金位置的一项业务。一个事实只能登记一次。

**项目合并经营账**：汇总项目整体收入、成本、应收应付、资金和盈亏，并抵销施工企业与我方公司之间项目内部载体关系的经营总账。

**主体分账**：按施工企业或具体我方公司展示其在项目中的合同、结算、收付款、垫资和往来，不改变项目合并经营结果。

**合同与承诺层**：记录合同额度、约定和尚未确认义务的经营视角。

**已确认经营层**：记录已经确认的收入、成本、应收、应付和往来的经营视角。

**实际资金层**：记录真实收款、付款、退款、调拨和资金位置的经营视角。

**施工企业账上项目资金**：业主已付给施工企业、尚未由施工企业拨给我方公司、付给下游或最终确认为施工企业扣费的项目资金。

**我方公司项目资金**：具体我方公司已经收到或为项目垫付，并由财务说明后续经营含义的项目资金。

**资金位置**：资金当前由施工企业或某家我方公司持有的事实，不等同于项目利润。

**应收应付**：已经确认但尚未完成收付的债权债务，必须明确债权人、债务人和所属项目。

**工资外部债权人**：已确认工资中的个税、社会保险、住房公积金或其他受控机构债权人；其权威身份是冻结的 `BusinessPartyVersion`，在经营账中只使用窄主体种类 `wage_external_creditor`。它不是下游相对方，也不因主数据后续变更改写工资版本。

**工资应付引用**：由已确认工资版本逐项目分摊与逐债权人明细形成的不可变、追加式应付引用。基础工资和补发生成正向引用；更正或冲销只追加指向原引用的调整，不覆盖原引用；实际核销和超额核销真值由后续应付核销域计算。

**债务主体**：依据合同、结算或其他真实费用事实对下游负有付款义务的施工企业或具体我方公司；不得因为其他主体代付而改写。

**实际付款主体**：真实完成银行付款或现金支付的主体；业主付款事实中可为业主，项目向下游付款时为施工企业或具体我方公司，可以与债务主体不同。

**主体间代付往来**：实际付款主体代替债务主体清偿下游款后，在两个主体之间形成的应收应付；只改变往来和资金，不重复形成项目成本。

**统一成本分类**：公司统一维护的项目成本归类口径，一级包括材料成本、班组及人工成本、专业分包成本、机械设备及租赁成本、现场施工及措施费用、项目日常费用、施工企业扣费和其他项目成本。

**财务对账状态**：我方公司项目收付款与外部财务账、银行流水或财务对账资料的比较结果，分为已与财务账核对、部分核对、尚未核对和存在差异；外部值不得覆盖系统经营事实。

## 盈亏与清算

**当前经营盈亏**：当前已确认收入减当前已确认成本。

**预计待清算费用**：尚未最终确认的管理费、税费及其他必要清算费用预计值。

**当前预计盈亏**：当前经营盈亏减预计待清算费用。

**最终确认盈亏**：对上结算、项目成本、税费、施工企业扣费和重大差异均已确认后的项目经营结果。

**当前可分配利润**：同时受可用项目资金和未分配预计利润约束，且已经足额保留下游应付款、待清算费用及其他必要准备后，可以提前分配的较低金额。

**未分配盈亏**：项目已经形成但尚未通过盈亏分配确认单分配到各参与公司的盈亏。

**暂分利润**：最终盈亏分配确认前，某家我方公司已经取得的利润性质金额，不自动等于该公司的最终份额。

**暂扣**：资金暂时留在施工企业，但性质或金额尚待清算的状态；不得直接等同于最终项目成本。

**最终扣费**：经确认归施工企业所有并计入项目最终成本的管理费、税费、保证金、保险费、手续费、派驻人员工资或其他扣费。

## 接管与更正

**经营账生效日**：项目开始优先通过建工智管办理正式业务的日期，不表示历史账已经完整。

**经营接管完成日**：适用历史场景已经覆盖、重大差异已经处理、影响盈亏的缺口已经清理并完成专业确认的日期。

**历史接管批次**：一个项目内对一组历史事实进行预检、复核和确认的受控工作单元。

**A 级事实**：逐笔业务及可靠依据完整的历史事实。

**B 级事实**：无法逐笔还原，但按受控颗粒度整理并具有可靠汇总依据的历史事实。

**C 级缺口**：只能证明大概金额或缺少可靠依据的历史资料缺口，不进入正式收入、成本、应收应付和利润。

**例外事后补录**：对真实已经发生、但无法补做事前流程的业务进行有原因、有依据、有复核的如实登记，不补造过去不存在的审批。

**更正**：保留原事实，通过追加记录修正其错误内容或经营影响。

**冲销**：保留原事实，通过反向记录撤销其全部或部分经营影响。

## 避免使用

- **挂靠企业、挂靠合同、挂靠模式**：带有不必要的定性，不作为用户界面标准词汇；统一使用“施工企业”和真实业务关系。
- **项目利润等于账上余额**：混淆经营结果与资金位置。
- **项目完毕**：颗粒度不足；应明确工程完工、对上结算完成、成本确认完成、清算完成、盈亏确认、盈亏分配或资金结清。
- **历史总余额**：不能替代逐笔事实或受控汇总事实，只能作为外部对账值保存和比较。
