# 统一业务录入领域词汇

本文件定义 Web 管理端结构化业务录入的用户语言。完整规则以 [`项目经营总账、施工企业经营接管与统一业务录入正式规格`](../../docs/specs/2026-08-12-project-operating-ledger-construction-enterprise-takeover-unified-entry.md) 为准。

## 核心词汇

**统一业务录入引擎**：让页面表格、单条表单、移动端卡片、只读详情和 Excel 共用同一份业务字段与校验规则的录入能力；不是用户自由搭建业务系统的低代码平台。

**业务字段定义**：字段的中文名称、填写说明、业务类型、必填规则、中文选项、岗位权限、校验和各展示方式的共同来源。

**银行流水候选选项**：页面只展示服务端返回的短效选项值、到期时间和中文摘要；不得展示或要求用户填写银行观察、认领、付款执行、共享分配或审批等技术编号，选项过期后必须刷新。

**逐轴分类选项**：页面为每条待分类资金分别展示服务端签发的应付、项目资金、主体往来和经营中文业务选项；提交只发送短效选择凭据，反向执行不展示重新分类入口。

**业务台账表格**：适合连续录入、批量修改、筛选、排序和复制粘贴的页面表格。对用户不称“数据表”“数据库表”或“技术多维表”。

**连续表格录入**：业务台账表格支持多行多列粘贴、方向键和回车连续填写、批量填值、草稿行增删复制、撤销未提交修改、冻结表头和关键列、搜索选择以及单元格中文错误定位。

**单条业务表单**：适合一张主单或少量字段逐项填写的结构化页面。

**移动业务卡片**：在手机上逐项填写和查看同一业务草稿的展示方式，不要求横向操作巨型表格。

**业务草稿**：已经自动保存但尚未由用户明确提交的内容；不进入审批和正式经营账。

**提交快照**：用户明确提交时冻结的业务数据、字段含义、选项和计算结果；后续字段变化不得改写该快照。

**业务整理编号**：用户在一次业务整理或接管批次内填写、用于关联明细的中文业务编号，不是数据库编号。

**资料来源**：说明事实根据来自纸质单据、财务账、银行流水、施工企业对账单、项目台账、经办人说明、多人核实或其他真实来源的业务字段。

**业务原值**：用户真实资料中的合同号、发票号、银行流水号、规格型号、单位、名称、备注、原条款和文件名；即使含有字母，也必须保持原值。

**个人视图**：用户保存的列宽、列顺序、隐藏列、筛选和排序偏好；不得改变业务字段含义、金额公式、必填规则、审批条件或正式事实。

**用户可填写入口清单**：列出所有页面、弹窗、台账表格、单条表单、移动端卡片和 Excel 录入入口的实施清单；每个入口必须标明统一字段迁移、旧入口关闭和同规则测试状态，清单未覆盖即不算全站完成。

**中文业务错误**：向用户说明发生了什么、为什么以及下一步如何处理的中文提示；不得直接展示原始异常、接口状态、程序字段或内部对象编号。

## 录入状态

**未提交**：内容仍是草稿，可以继续编辑。

**保存中**：系统正在保存草稿，不表示已经提交。

**已保存**：草稿已经保存，不表示已经进入审批或正式经营账。

**保存失败**：当前输入仍须保留，用户可以修正问题或重试。

**待复核**：内容已经提交，等待岗位按业务职责确认。

**已进入正式账**：必要确认完成，业务事实已经进入正式经营账。

**需要补充复核**：后续更正或新事实可能改变原确认结论，需要重新确认。

## 避免使用

- **表格就是业务记录**：表格只是录入和展示方式，正式事实仍属于具体业务单据或接管批次。
- **自动保存就是提交**：自动保存不得发起审批或进入正式账。
- **上传 Excel 就完成导入**：上传先形成可检查的页面草稿，正式批次仍须明确提交和复核。
- **隐藏技术列用于往返**：用户下载、填写和上传的 Excel 不能包含隐藏技术工作表、列或单元格；使用中文业务编号或业务整理编号关联。
- **用户自定义公式**：核心收入、成本、应收应付、资金和利润只能由正式业务规则计算。
- **技术编号、英文状态、原始错误**：不得进入普通用户可见页面、提示、Excel、PDF、导出或审计业务详情。
