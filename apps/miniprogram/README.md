# 建工智管小程序端

P2 移动端最小骨架，定位为现场审批和附件采集工作台。

当前范围：

- 移动待办列表：读取后端 `/api/me/work-items`。
- 待办详情页：展示业务编号、节点、项目、金额、停留时间和下一步。
- 手机号 + 当前密码登录：调用后端 `/api/auth/login`，本地保存访问令牌。
- 移动端直接审批：合同、结算、付款、项目支出审批待办可在详情页通过或驳回。
- 附件拍照上传入口：调用微信拍照/相册选择，预留上传到后端私有文件接口。

接入生产前仍需确认：

- 微信小程序 `appid`。
- 小程序发布版本和体验版成员。
- 是否需要给移动审批再叠加二次确认密码。
