# Triage Labels

The engineering skills use five canonical triage roles. Use the following
GitHub label strings for this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a triage role, apply the corresponding GitHub label from
this table. Edit the right-hand label column here if the repository vocabulary
changes later.
