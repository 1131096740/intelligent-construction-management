# P0-6A 真实试运行执行与问题闭环 Runbook

日期：2026-07-03
状态：真实试运行执行模板
范围：1 个真实项目、约 20 个历史合同、3-5 个活跃合同；用于 Go-Live Gate 通过后的每日执行、问题闭环和结束验收。

## 使用原则

- 本文只定义执行机制，不代表真实试运行已经发生。
- 仓库内只保留脱敏模板；真实姓名、手机号、账号、密码、合同金额、银行账号、附件链接、密钥和完整数据库连接串不得写入本文或提交仓库。
- `verify:production-readiness` 只做生产等价环境只读辅助检查；`verify:trial-run` 只连接本机 seed/test 数据，不得连生产库或真实 COS。
- 每日只推进 P0 主链路：历史合同接管、结算、付款、综合费用、实付、凭证、文件权限、审计和问题闭环；不扩展 OCR、Excel 导入、小程序、大屏、经营驾驶舱或新审批后台。
- `super_admin` 只做技术运维，不替代业务岗位录入、复核、审批或签字。

## P0 / P1 / P2 处理规则

| 等级 | 判定标准 | 处理时限 | 试运行影响 | 关闭要求 |
| --- | --- | --- | --- | --- |
| P0 | 越权、资金错误、付款绕过、seed 密码风险、生产安全失败、备份不可恢复、核心链路中断 | 当日立即处理 | 暂停相关真实业务；必要时整体 No-Go | 修复、复测、负责人和老板确认后关闭 |
| P1 | 影响效率或需人工控制，但不直接造成资金或安全事故 | 约定日期内处理 | 可 Conditional Go，但必须有临时控制措施 | 负责人复测，老板或授权负责人接受剩余风险 |
| P2 | 不影响本次单项目 P0 试运行 | 进入后续待办 | 不阻断试运行 | 记录到后续优化清单 |

P0 例子：

- 未确认接管或历史余额未确认仍能发起付款。
- 超额付款未被后端拒绝。
- 非授权账号能下载敏感文件，或下载无审计。
- seed 通用密码能登录真实试运行账号。
- 数据库或附件无法从备份恢复。
- 真实合同金额、密码、密钥或附件直链进入共享文档或仓库。
