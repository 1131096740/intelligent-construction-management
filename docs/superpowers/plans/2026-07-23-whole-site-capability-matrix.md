# 建工智管整站受控改造：现状能力矩阵

日期：2026-07-23
状态：阶段 0 已确认；生产只读快照与用户决议已纳入实施基线

分类定义：

- **保留**：保留当前实现和数据，仅纳入统一页面/读取模型。
- **替换**：新实现承担未来写入；旧实现继续只读直到退役门禁通过。
- **迁移**：保留业务语义与历史数据，新增兼容读写路径或前向数据结构。
- **废弃**：停止新入口；必须保留用户影响、数据处理和回退方案。

| 旧能力 | 当前承载 | 分类 | 目标与迁移方式 | 用户影响、数据处理与回退 |
| --- | --- | --- | --- | --- |
| 手机号登录、改密、会话撤销 | auth | 保留 | 继续作为唯一 Web 身份入口 | 无数据变更；认证异常可回退现有登录页 |
| 原生微信登录与小程序骨架 | `apps/miniprogram`、`/auth/wx-login` | 废弃 | 按已批准移动 Web 退役计划分阶段关闭 | 先只读统计使用和 `wxOpenid` 依赖；保留 Web 登录回退；删除运行时和字段需单独授权 |
| 管理端外壳和中文路由 | `AdminLayout`、route records | 迁移 | 收口目标导航，旧英文/旧中文路径保留 redirect | 收藏链接继续可达；新导航异常可回切旧路由映射 |
| 首页工作项 | Home + `/me/work-items` | 迁移 | 成为统一工作项投影消费者 | 不改任务归属；投影异常保留旧首页读取 |
| 侧栏导航 | `AdminLayout` | 替换 | 使用同源工作项角标和目标分组 | 旧菜单先 redirect；委托台账移出主导航前保留直达 |
| 全局搜索 | GlobalSearch | 保留 | 作为首个共享工作台金丝雀 | 权限过滤不变；出现回归可回退页面组件 |
| 审批中心 | ApprovalCenter + approval/me | 迁移 | 固定待我审批、已审批、我发起、全量审批视图 | 转交/委托历史只读保留；旧视图可临时保留兼容入口 |
| 审批引擎 | ApprovalInstance/ActionLog/Delegation | 保留 | 继续承担冻结节点、OR 签、退回、委托和审计 | 不迁移审批历史；新页不得绕过服务端审批动作 |
| 个人签名图片上传 | User.signatureFileId、个人设置 | 替换 | 新增 Canvas 签名版本和冻结引用；旧签名只服务历史审批 | 未来审批需新签名；保留旧预览和历史 PDF；缺少新签名时阻断新审批 |
| 合同工作台与草稿 | ContractWorkbench、ContractVersion | 迁移 | 四步页面、手动草稿、共享网格和任务卡 | 不改合同/版本主键；自动保存退役前保留本地恢复与兼容读 |
| 合同管理/详情 | ContractList/Detail | 迁移 | 与合同工作台收口为一个根单入口 | 旧 URL redirect；不删除版本历史 |
| 合同编号规则 | ContractNumberRule | 迁移 | 未来合同首次成功保存时接入统一日流水服务；旧规则仅服务历史解释 | 已发编号永不改写、不回收断号；切换故障保留兼容读和开关回切，不重新分配已取号码 |
| 合同模板、版式、条款、场景 | contract-template/layout/scenario | 保留 | 纳入合同工作台治理入口 | 版本化发布、私有文件和历史读取不变 |
| 合作单位档案 | BusinessParty/Snapshot | 保留 | 继续作为正式合同乙方主数据 | 冻结快照不改写；零星商户不自动转档案 |
| 合同用章、归档、生效 | ContractSealTask/Archive | 保留 | 页面统一，后端归档生效不变量不变 | 文件和确认历史不改写 |
| 合同变更/补充协议 | ContractVersion change/supplement | 保留 | 统一展示在合同根单详情 | 单活跃变更、金额阈值和历史引用保持 |
| 历史合同接管 | ContractTakeover | 迁移 | 独立工作台视图和财务补凭证任务 | A/B/C 等级、已接管事实和文件不重建 |
| 项目经营总览 | ProjectOperatingOverview | 替换 | 收口为项目工作台/详情页签 | 经营指标权限不变；旧路由 redirect |
| 项目花名册 | ProjectRosterMember | 迁移 | 成为项目详情页签与选择器事实源 | 无账号成员继续不能登录；不创建占位账号 |
| 项目生命周期 | Project | 迁移 | 后端按未收口事项检查状态变更 | 不允许新前端下拉绕过；旧状态保持可读 |
| 结算工作台/草稿 | SettlementDraft/Settlement | 迁移 | 四步页面、共享网格、期间和签章事实 | 期间、合同版本和归档生效规则不变 |
| 结算 Excel 预检/模板治理 | SettlementImport/Template | 保留 | 作为网格录入辅助和治理页 | 不允许批量绕过正式创建；已冻结版本继续可读 |
| 结算内部签名合成件 | SettlementSignedDocument | 迁移 | 接入新签名版本和正式文件预览 | 原乙方文件与历史合成件不覆盖 |
| 合同付款申请 | PaymentRequest | 迁移 | 进入统一资金办理工作台 | 结算/预付款容量、审批和版本引用保持 |
| 实际付款、退款、凭证 | PaymentExecution/Allocation | 保留 | 统一资金工作台办理，多次实付继续独立 | 幂等、余额、凭证、退款上限和审计不变 |
| 项目资金、财务入账 | FinanceRecord/Project finance | 保留 | 由统一资金读取模型投影 | 不重算历史金额或财务分录 |
| 零星采购申请 | SpotProcurement | 迁移 | 使用共享工作台组件，不改状态机 | 采购编号、审批、材料范围保持 |
| 零星材料付款 | SpotProcurementPayment | 迁移 | 保持来源单自动草稿和四步办理 | 不新增误导性“新建”；冻结税率/渠道不改写 |
| 收货确认、委托、复核 | SpotProcurementReceipt | 迁移 | 保持任务页，接入统一工作项 | 收货、差异、退款和照片水印规则不变 |
| 零星票据、无票、异常 | InvoiceRecord/Allocation/Exception | 保留 | 继续作为零星采购专属能力 | 不扩张成费用发票系统；现有分摊和证据不改写 |
| 旧项目支出申请 | ProjectExpenseRequest | 替换 | 冻结为历史兼容域；新费用/借款不再创建旧记录 | 历史详情、PDF、附件和审计继续可读；不自动拆分/迁移 |
| 旧项目支出实付/财务归档 | ProjectExpenseExecution/FinanceRecord | 保留 | 历史读取和归档保留 | 不改历史资金事实；新费用走独立账本 |
| 费用报销 | 旧项目支出中的 reimbursement | 替换 | 已建立独立 `ExpenseClaim`、费用行、真实/无账号代办快照与 `BX` 日流水草稿；已实现四节点审批提交/办理，提交时冻结具体有效审批人，非项目事实证明人是唯一冻结候选；同人自审须当前密码、Canvas 签名快照和审计。项目报销提交时按已实际放款 FIFO 预留同一报销人+项目余额并冻结公司补付差额；后续补预留释放/正式冲销、附件、补付与 PDF | 旧报销只读；新旧列表明确标识来源；可关闭新入口回到历史只读 |
| 借款、冲销、员工还款 | 旧 loan_reserve 子类 | 替换 | 已建立独立借款账户、不可变分录、预留和还款确认模型，并由 `JK` 日流水新入口创建草稿、冻结审批链与分次实际放款；每笔放款须登记人上传凭证，在锁定申请/账户的事务中追加分录和余额投影。后续补 FIFO、还款确认、反向分录和 PDF | 旧借款只读；不把旧余额自动推断为新账本 |
| 正式编号 | 合同/结算/零星/项目支出各自实现 | 迁移 | 新共享服务按领域事务适配；合同先在首次成功保存时切换日流水 | 历史号不变；切换仅影响新写入；服务异常不回收号码 |
| 正式 PDF/审批单 | ApprovalForm、领域 renderer、PdfDocument | 迁移 | 建立版本语义和统一预览，复用服务端生成 | 不使用浏览器打印替代；旧 PDF 只读保留 |
| 私有文件上传下载 | FileObject/FileService | 保留 | 新域接入绑定、替换链、短票据和审计 | 不暴露对象键；下载回归可切回既有票据路径 |
| 资料库 | ArchiveRecord/ArchiveList | 迁移 | 成为业务归档索引，收口授权投影 | 不变成网盘；旧归档继续可读 |
| 审计日志 | AuditLog/AuditList | 保留 | 补齐新域关键动作和字段差异 | 不删除历史审计；敏感元数据继续脱敏 |
| 公司主体 | CompanyEntity/Version | 保留 | 归入系统配置，业务选择后冻结快照 | 不改历史主体快照 |
| 组织权限 | Organization/UserPosition/ProjectMember | 保留 | 配合统一可见范围和 `availableActions` | 不以 super_admin 自动扩权；异常清理单独授权 |
| 草稿保留/放弃/复制 | draft-retention、领域草稿 | 迁移 | 新域采用同一生命周期原则 | 不批量删除现有草稿；旧草稿先兼容读写后退役 |
| 新增或修改的数值输入 | 合同、结算、零星采购和后续费用域的输入/导入边界 | 迁移 | 所有未来新增或修改写入统一限制最多两位小数；历史记录、冻结文件和已发布模板只读保留原精度 | 旧草稿再次保存前须人工调整为两位；禁止自动舍入、批量改写或重算历史金额 |
| 设计 token 与 UI 检查 | `design-tokens.css`、`check:ui` | 迁移 | 扩展 token 和治理覆盖，逐页移除 allowlist | 视觉回归可按页面回退；不引入第二组件库 |
| 多维编辑表格 | 各领域自定义编辑器/TDesign 表格 | 替换 | `JgBusinessGrid` 适配 RevoGrid Community；普通台账仍用 TDesign | 先 POC；失败回到设计评审，不引入 Pro 或低代码 |
| 响应式治理 | responsive CSS、结构/E2E 测试 | 迁移 | 覆盖全部保留页面和九档视口 | 每页保留单一滚动所有者；问题页可独立回退 |
| 浏览器支持 | Chromium Playwright | 迁移 | 增加 WebKit 自动金丝雀与真机手工 UAT | 生产支持范围以验收矩阵为准；不以 Chromium 单测代替 Safari/iOS |
