# 建工智管 Web Admin V2 UI 设计方案

## 设计判断

Reading this as: 企业级工程管理后台 for 合同部、财务部、项目管理人员；信任优先、台账优先、内控优先；采用 TDesign/政企后台语言，而不是展示型 SaaS Dashboard。

设计参数：

- DESIGN_VARIANCE: 3
- MOTION_INTENSITY: 1
- VISUAL_DENSITY: 8

## 目标

第二版必须像真实企业系统，而不是像 AI 生成的演示后台。

核心目标：

- 让合同、结算、付款三类业务按严格顺序绑定。
- 让每个阻塞事项都能看到责任部门、停留时间、下一步动作。
- 让付款审批通过和实际付款完成在界面上始终分开。
- 让合同部上传/确认归档、财务读取归档件的责任边界清楚。

## 总体方向

采用“政企台账系统 + 单据详情页 + 阻塞事项工作台”的混合方案。

- 工作台：不做大屏，不做营销式卡片，主区是阻塞事项队列。
- 合同台账：高密度表格为主，顶部只保留紧凑统计条。
- 合同详情：按单据系统组织，包含主信息、版本、归档、审批、关联结算/付款。
- 移动端：只承载待办、审批、归档确认，不复制完整后台。

## 页面 1：我的待办

用途：每天打开系统首先处理阻塞事项。

首屏结构：

- 顶部栏：系统名、当前模块、当前角色。
- 左侧导航：我的待办、合同管理、结算管理、付款管理、归档资料、审批配置、审计日志、基础数据。
- 顶部统计条：合同待归档、结算待确认、付款待审批、待实际付款、超账期。
- 主表：阻塞事项队列。
- 右侧：今日处理原则。

阻塞事项队列表字段：

- 类型
- 业务单据
- 当前节点
- 责任部门
- 停留时间
- 下一步动作
- 操作

示例节点：

- 合同 / 待归档确认 / 合同部 / 主管确认归档
- 结算 / 待归档确认 / 合同部 / 确认结算归档
- 付款 / 董事长或总经理 / 总经办 / 二选一审批
- 付款 / 待实际付款 / 财务部 / 登记付款凭证

## 页面 2：合同台账

用途：合同部和管理人员查询合同版本、生效状态、付款条款版本、归档状态。

设计规则：

- 不使用大 KPI 卡片。
- 统计信息压缩为横向数字条。
- 表格行高建议 44-48px。
- 状态标签小尺寸、低饱和。

表格字段：

- 合同编号
- 合同名称
- 项目
- 相对方
- 金额
- 当前版本
- 当前节点
- 责任部门
- 更新时间
- 操作

筛选条件：

- 项目
- 合同状态
- 归档状态
- 付款条款版本
- 关键词

筛选区设计要求：

- 必须是紧凑查询条，不做大表单。
- 桌面端优先一行展示，空间不足时两行换行。
- 查询、重置按钮保持小尺寸，不允许横向撑满。
- 字段高度控制在 28-32px，标签使用 12px 辅助文字。
- 只有手机窄屏才允许单列堆叠。

## 页面 3：合同详情

用途：查看合同当前版本、付款条款版本、用章归档状态和后续结算/付款阻断关系。

顶部主信息：

- 合同编号
- 当前状态
- 当前版本
- 付款条款版本
- 责任部门
- 当前处理人
- 下一步动作

内容分区：

- 基础信息
- 生效流程与阻断点
- 付款条款版本记录
- 关联结算 / 付款

生效流程：

1. 合同审批
2. 用章
3. 归档上传
4. 主管确认
5. 合同生效

明确规则：

- 合同未生效，不能发起结算。
- 结算未生效，不能创建付款申请。
- 合同条款变化必须通过合同变更或补充协议生成新版本。
- 待用章状态下的主动作是发起/办理用章，不应出现上传归档件。
- 用章完成后才进入归档件上传，再由合同部主管确认。

## 页面 4：移动端待办

用途：手机上处理待办，不承载完整后台。

内容：

- 我的待办列表。
- 每条待办显示业务类型、单据号、责任部门、停留时间、下一步动作。
- 底部导航：待办、合同、结算、付款。

移动端不做：

- 完整合同台账。
- 复杂筛选器。
- 大量统计卡片。

## 去 AI 感规则

- 不做展示型 Dashboard。
- 不使用大号彩色 KPI 卡片。
- 不使用过多圆角、阴影、渐变、装饰图形。
- 不使用泛滥的彩色 pill 标签。
- 不用“闭环风险提醒”这类演示口吻，改成系统语言：阻塞事项、待确认归档、待实际付款、超账期。
- 不用“批量确认”处理审批、归档、付款等内控动作；可保留批量催办、批量分派等非最终确认动作。
- 页面主视觉让位给表格、单据、审批记录和归档记录。

## 实现建议

Vue/TDesign 实现时优先使用：

- `t-layout`
- `t-menu`
- `t-table`
- `t-form`
- `t-tag`
- `t-descriptions`
- `t-tabs`
- `t-timeline`
- `t-drawer`
- `t-dialog`

CSS 方向：

- 背景：`#f4f6f9`
- 面板：`#ffffff`
- 边框：`#dce1e8`
- 主色：TDesign 蓝
- 状态色：低饱和蓝、绿、橙、红
- 圆角：3-4px
- 表格行高：44-48px
- 页面字号：12-14px 为主
