# 历史已签合同样本分析与模板优化建议

> 分析时间：2026-07-01
> 结论用途：用于校准后续合同生成能力，不作为历史合同原文沉淀。
> 脱敏原则：本文不记录真实合同金额、联系人、电话、身份证号、税号、盖章图样等敏感信息。

## 一、需求口径

- 版式、字体、页边距、封面、页眉页脚、分页、表格观感，以“公司级正式合同母版 1.0”为主。
- 条款内容、业务字段、附件组成、清单合并方式，优先尊重公司历史已签合同。
- 历史合同不直接原样转成模板，先作为真实样本库，用来校准系统生成合同的完整度。
- 本轮只输出产品分析和后续开发清单，不改业务代码。

## 二、样本范围

本轮对比两类样本：

1. 已签 PDF 合同样本
   - 扫描全能王 2026-01-23 16.43.pdf
   - 5、零星材料采购合同范本-云大.pdf
   - 7、砌体材料合同范本-云大.pdf
   - 8、砂石料合同范本-云大.pdf
   - 免烧砖采购合同-民大附中.pdf

2. 近期拟签 Word + Excel 合同样本
   - 顶管管材采购合同 + 价目表
   - 外购土方采购合同 + 价目表
   - 流水石采购合同 + 价目表

识别情况：

- 4 份 PDF 范本有文字层，可用于条款结构提取。
- 扫描全能王 PDF 无文字层，适合作为版式和字段参考；若要精提条款，需要 OCR 或人工录入。
- 3 组 Word + Excel 均可读取，Excel 价目表结构清晰，应作为最终 Word 的合同组成部分合并生成。

## 三、总体判断

这批合同全部可以归入当前系统的 `material_purchase` 材料采购大类，不建议为“砂石料、砌体、免烧砖、顶管、外购土方、流水石”分别新增一级合同类型。

更合适的设计是：

- 一级合同类型：材料采购合同。
- 二级材料子类：零星材料、砌体材料、砂石料、砖类材料、管材/预制构件、土石方材料、其他材料。
- 子类控制默认字段、清单列、条款包、附件建议和价目表表头。

这样最省，也最稳：审批流、归档、结算、付款逻辑不需要膨胀；合同生成仍能覆盖不同材料品类的真实差异。

## 四、合同结构发现

### 1. PDF 范本是“完整长条款模板”

云大类范本普遍包含：

- 信息型封面：合同名称、合同编号、买卖双方、建设单位、工程名称、工程地点、签订地点、签订日期。
- 正文开头：买方、卖方、法律依据、项目背景。
- 主条款：
  - 材料名称、规格、价格、生产厂家、数量、金额
  - 质量要求、技术标准、质量责任
  - 交货方法、运输方式、运费承担、到货地点
  - 发票开具
  - 材料验收
  - 供应期限
  - 货款结算、付款时间
  - 双方权利义务
  - 不可抗力
  - 争议解决
  - 合同生效
  - 其他约定事项
- 部分范本还有包装物、廉洁/安全/告知书类附件。

### 2. 公司近期合同是“短版实务模板”

近期 Word 合同更短，通常包含：

- 合同标的和上限总价或暂估价
- 质量标准
- 交货地点、运输方式、费用承担
- 计量/验收方式
- 付款方式
- 价格调整
- 违约责任
- 争议解决
- 合同份数、生效和解除
- Excel 价目表作为合同附件

产品上应同时支持两种风格：

- “正式长版”：适合金额较大、外部单位要求严格、条款完整的材料采购。
- “公司短版”：适合近期公司实际使用的普通材料采购，但仍套用公司母版版式。

## 五、字段清单建议

### 1. 当前材料采购模板已覆盖

当前系统已有：

- 项目名称
- 交货地点
- 交货期限
- 质量标准
- 税率
- 结算方式
- 材料清单
- 运费清单
- 付款及结算条款
- 供应商报价单附件

这些是基础能力，可以继续保留。

### 2. 建议补充为材料采购通用字段

建议下一轮补充以下字段，均服务于历史合同真实写法：

- 建设单位
- 工程名称
- 工程地点
- 签订地点
- 签订日期
- 材料子类
- 合同价格类型：固定总价、上限总价、暂估价、据实结算
- 运输费用承担：含运费、不含运费、乙方承担、甲方承担
- 卸货责任：甲方卸货、乙方卸货、双方约定
- 计量方式：现场收方、送货单、过磅、按实测长宽高、按验收数量
- 指定收货人信息：姓名、联系方式、证件信息；其中证件信息属于敏感字段，只在业务录入和合同生成时使用，不进入普通列表展示。
- 发票类型：普通发票、增值税专用发票
- 发票税率
- 付款模式：预付款、过程款、月结、验收后付款、安装/检测后尾款
- 价差调整规则：固定单价、浮动单价、政府或市场调价通知
- 争议解决地
- 合同份数

### 3. 建议保留合同员可编辑的关键条款

以下条款应继续允许合同员编辑：

- 付款比例和付款节点
- 结算周期
- 计量/验收方式
- 质量标准
- 交货地点和供货期限
- 违约责任
- 价格调整
- 争议解决
- 其他约定事项

长条款如不可抗力、合同生效、廉洁/安全通用告知，可作为固定条款，由模板版本控制。

## 六、Excel 价目表合并规则

历史样本明确说明：Excel 不是普通附件，而是完整合同的一部分。

建议规则：

- 合同员可上传 Excel 价目表，也可在系统清单里录入。
- 若上传 Excel，系统生成 Word 时应把 Excel 清单转换为 Word 表格，追加为“附件X：材料采购价目表”。
- 原始 Excel 文件仍作为附件留存，便于追溯。
- 没有上传 Excel 时，不生成价目表附件占位。
- 若系统清单和 Excel 同时存在，优先以系统确认后的清单数据生成 Word，Excel 作为来源附件。

价目表应支持的列：

- 序号
- 名称
- 设计要求/质量要求
- 规格型号/尺寸规格
- 施工部位/用途
- 单位
- 暂估数量
- 含税单价
- 含税合价
- 不含税单价
- 不含税合价
- 税率
- 税额
- 备注

最低实现不需要做复杂 Excel 排版克隆，只要做到：

- 表题居中
- 项目名称行保留
- 表头清晰
- 数字列右对齐
- 备注可换行
- 多页表格表头重复
- 表格边框、字体、字号符合母版

## 七、附件与签章发现

历史 PDF 中出现了营业执照、授权、身份证、安全/告知书、廉洁等附件或关键词。

当前系统已经有较好的附件基础：

- 图片附件按 A4 居中适配。
- 身份证人像面/国徽面同页上下排列并标注。
- 未上传附件不占位。

建议补充：

- 材料采购也允许配置“安全告知书/廉洁承诺/授权文件”等固定或按需附件。
- 附件类型应由模板版本控制，不按合同类型写死。
- 签章页继续使用公司母版统一左右栏样式，不照搬历史 PDF 的盖章扫描位置。

## 八、当前系统差距

### 已满足

- 有材料采购一级合同类型。
- 有通用合同兜底模板。
- 能生成 DOCX/PDF 初稿。
- 已支持附件图片居中、身份证双面同页。
- 已支持合同员/合同部主管创建草稿并发起审批。
- 已建立公司级正式合同母版 1.0。

### 需要补齐

- 材料采购缺少二级材料子类。
- 材料采购字段还不足以覆盖封面信息、签订地点、建设单位、计量方式、价格类型、价差调整等历史写法。
- 当前材料清单列偏少，覆盖不了顶管、土方、流水石和零星材料价目表。
- Excel 价目表尚未作为 Word 合同正文附件合并。
- 材料采购缺少“长版/短版”两套条款包。
- 扫描版历史合同如果要精提内容，后续需要 OCR 或人工录入。

## 九、推荐下一轮实施边界

下一轮不做复杂能力，建议只做最小可用闭环：

1. 在材料采购模板里增加“材料子类”字段和几个子类选项。
2. 扩展材料清单列，新增列先全部做可选。
3. Excel 导入后复用现有清单数据结构，不新增复杂 Excel 模板引擎。
4. Word 生成时把材料清单渲染为“附件X：材料采购价目表”。
5. 新增材料采购长版条款包和短版条款包。
6. 保持母版版式统一，不按历史 PDF 逐份复制版式。

暂不做：

- 不为每种材料新增一级合同类型。
- 不做扫描 PDF 自动 OCR 入库。
- 不做历史合同自动反向生成模板。
- 不做 Excel 原样像素级还原。

## 十、产品结论

这批历史合同对项目非常有参考意义，核心价值不是“复制旧合同”，而是告诉我们材料采购合同真实业务里必须支持：

- 信息型正式封面
- 材料采购子类
- 长短两套条款风格
- 可编辑的付款、结算、验收、违约、价差条款
- Excel 价目表合并进最终 Word
- 多列、多页、可换行的材料清单表格
- 按需附件，不上传不占位

因此，建工智管 Phase 1 后续合同模块的正确方向是：统一母版 + 材料采购子类化 + Excel 清单附件化，而不是把每一份历史合同都做成独立模板。
