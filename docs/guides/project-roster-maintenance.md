# 项目花名册维护

入口：登录后打开 **项目花名册**，先选择项目。没有人员的新项目也会出现在项目选项中。

## 调入人员

1. 点击“调入人员”，选择已有人员，填写调整原因。
2. 点击“预览调整”，核对人员和项目。
3. 输入本人当前登录密码，点击“确认调入项目”。

人员尚无账号时，先在“组织权限”创建人员账号或审核其入职申请。调入只增加项目归属；需要合同经办、审批等岗位时，在“组织权限”另行安排。

## 调出人员

1. 在对应人员行点击“调出项目”，填写调整原因。
2. 点击“预览调整”，核对将撤销的当前项目岗位和待办影响。
3. 输入本人当前登录密码，点击“确认调出项目”。

调出保留员工账号、其他项目任职和历史业务记录。已有单据指定了审批人的，需要先办完或通过原审批入口完成交接；仅新增同岗位人员不能自动接手旧单。还有本项目转审或有效委托任务时，也应先办完任务或完成相应交接，再重新预览。人员需要重新登录后使用调整后的权限；仍持有公司岗位的人员，继续保留该公司岗位赋予的跨项目职责。

## 谁可以维护

| 操作人 | 可以维护的人员 |
| --- | --- |
| 董事长 | 普通人员、管理层、项目经理、全部财务及其他重要岗位人员 |
| 综合部主管 | 普通人员；重要岗位及已标记由董事长管理的人员仍由董事长处理 |
| 其他岗位 | 查看其有权查看的花名册，不能调入或调出 |

本人项目归属由另一位有权管理员维护。调出项目和停用账号不同；员工离职时，还应通过“组织权限”办理停用。

## 与项目建账的关系

花名册解决人员归属，不自动建立经营账。每个项目还需核对挂靠公司、我方参与公司、财务和合同经办人、经营账启用日期；已有历史业务的项目还需核对合同、结算、已付和未付金额。真实资料确认后再录入，不用虚构零金额补齐。
