# 基础资料维护操作单

公司级综合部主管和董事长负责以下维护。其他岗位按原分工查询和办理业务；合同审批、结算、付款权限不变。

| 要做什么 | 操作入口 |
| --- | --- |
| 新增合作单位或挂靠施工企业 | 合作单位 → 新增合作单位 |
| 修改合作单位、停用或重新启用 | 合作单位 → 打开对应单位 → 修改资料／停用／重新启用 |
| 新增我方公司、修改名称或地址 | 我方公司主体 → 新增我方公司，或列表中的修改 |
| 停用或恢复我方公司 | 我方公司主体 → 对应公司的停用／重新启用 |
| 新增项目、修改项目名称 | 项目经营 → 项目维护 → 新增项目／修改项目 |
| 空项目停用或恢复 | 项目经营 → 项目维护 → 停用与恢复 |
| 设置施工企业或调整参与公司 | 项目经营 → 选择项目 → 经营档案中的施工企业、参与公司 |

停用后资料保留，可以重新启用。已有业务的项目不能直接停用，应走原结项流程，继续查询历史、办理尾款。已有业务引用的我方公司会提示暂不能停用，避免影响付款；原历史合同仍可匹配历史停用主体。合作单位停用后不再接受新业务引用，原合同快照继续保留。

项目已有正式经营事实后，施工企业不能直接更换。项目参与公司的退出继续按已有生效时间和业务引用规则检查。

如果同时有另一位同事修改资料，系统会提示刷新后再保存；不要反复点击。权限提示出现时，先确认账号具有公司级综合部主管或董事长岗位。
