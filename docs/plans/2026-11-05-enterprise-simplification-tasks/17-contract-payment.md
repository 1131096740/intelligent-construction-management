## 验收条件

- [ ] PAY-01：合同付款由综合部发起；带出主体、最新已确认结算、累计已付/待付占用/可付、合同文本及附件，不重复上传。
- [ ] PAY-02：可付40万时仍明显展示合同付款时间/比例/条件；超过约定80%但不超资金业务余额不因此拦截；复杂验收条件由人员判断。
- [ ] PAY-03：按支付口径累计结算扣有效净已付及所有尚未支付申请占用；审批中/批准待付/部分剩余均占用；退款、核减和撤回按事实释放，不重复扣历史起点。
- [ ] PAY-04：调减确认后，仅合计剩余待付超过新可付款余额才暂停相关申请；同合同多个申请超限时都暂停，不自动挑先付者；余额足够照常办。
- [ ] PAY-05：可撤回/调整未付部分并重提全体审批；已付不动。后续新结算使余额够覆盖时自动解除暂停，不必额外核对动作才能解除。
- [ ] PAY-07：我方公司即使未结算也可按合同发起预付款审批；不自动判断比例；预付款计累计已付，后续自动汇总抵已付，不重新登记或按最早期次隐含分摊。
- [ ] PAY-08：预付30、累计结算20显示尚未结算预付款10，普通结算可付为0；不同合同预付10与欠款20分别显示，不自动跨合同抵扣。
- [ ] PAY-09：其他/服务合同保留按合同直接申请、分次付款路径；无确定合同总价且无结算时提示无法计算余额，金额由申请和审批人员判断，不将未知当0或虚构上限。
- [ ] PAY-10：收款单位/开户行/账号可带出或手填修改；当前申请修改不自动改共用档案；这是收款对象资料，与不维护我方真实银行账户是两回事。
- [ ] 并联岗位包含合同主管；提交/通过/实付重校余额，别的在途申请也占用，不能只读本期金额。
- [ ] 负结算不足暂停受影响未付总量，够则继续；已付不改，未付撤回重审，补结算容量恢复自动解除。
- [ ] 明确预付用途与未结算预付、超付差额；未知总价/结算其他合同不虚构0上限；收款信息本次修改不改单位档案。
