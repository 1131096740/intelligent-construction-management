## 验收条件

- [ ] APR-01：按本规格岗位表，同时给所有必需岗位派待办，须各岗位完成；总经理/董事长一人即可；不新增通用可编辑流程设计器。
- [ ] APR-02：驳回填原因、不签字；结束本轮、其他未处理待办关闭；原制单人修改后新一轮全部重审。审批中不由审批人改金额，需改10为8则驳回重提。
- [ ] APR-03：没有签名先设置；签批冻结当时本人签名；后来修改个人签名不改已有签字；每个兼任岗位单独审批记录。
- [ ] APR-05：部分已通过仍可撤回草稿，重提从所有岗位重新签；已全通过不能整体撤回，部分实付仅调整未付部分并重新审批。
- [ ] APR-11：已配置人员先并联办理；缺岗显示待配置、不自动跳过；补齐后通知新办理人；离职调岗后新人处理未办职责，旧已办记录不变。
- [ ] 真实PG竞争验证双同意/同职责抢办/最后同意与拒绝，仅唯一终态，旧轮动作不生效。
- [ ] 并联状态可在现有详情公开查看；缺岗位不跳过，补人后只唤醒缺失职责。
- [ ] 审批通过事件与业务转移同事务，其他领域后续逐片迁移，不全站同时破坏旧消费者。
