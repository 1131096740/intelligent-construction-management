## 验收条件

- [x] CON-01：三种合同关系与材料采购/机械租赁/劳务分包/专业分包/其他五种业务类型独立选择；没有合适类型选其他。
- [~] CON-02：表内新合同用工作台生成并审批；表外/对上可生成审批，也可不审批上传双方已签PDF/照片并登记台账；三类均可历史接管。
- [~] CON-03：工作台内填写信息与合同正文两标签，各占完整主要区域；正文是可编辑的完整合同预览，不只是文件状态或外链。
- [x] CON-04：项目、合同名称、合同关系、甲方、乙方为生成前必填；清单、金额按实际约定填写；不额外把旧模板中所有字段硬设必填。
- [x] CON-05：已有单位可搜索；新名称可直接用于当前合同，但不自动生成公司共用档案；档案由指定维护岗位处理。
- [x] CON-06：清单有数量/单价时计算；框架未约定数量或总价可留空；包干填内容与总价、不强制清单数量；完整性不足时标部分金额待确定，不把部分合计称最终总价。
- [x] CON-07：付款方式及约定采用一个文本框记录付款时间/比例/条件，不强制拆比例/日期/阶段，不推荐或自动执行付款条件；结算方式按真实约定简单填写。
- [~] CON-08：明确区分含税/不含税金额口径，默认含税、默认以含税单价填写，按实际约定可选不含税并标明；税率在合同约定。新旧合同未确定税率/发票种类可留空或待补充；发票种类含普通/增值税专用/无发票/待补充，无票不自动将未知税率当0；结算不重复填税率，不因后补税率改写已确认金额。
- [x] CON-09：合同员自己选择对应模板，系统不推荐；生成时带入已填关键信息。
- [~] CON-23：新合同系统自动生成业务编号；历史/线下已签合同按原编号，原无编号允许空；不暴露数据库ID或虚构原编号。
- [x] BAS-02：系统展示真实依据和关键金额；不做附件 OCR、金额识别或自动比对，不自动判断验收、付款条件等线下事实。金额、状态、权限、防重仍在后端事务中执行。
- [ ] 项目/名称/关系/甲乙为关键必填；数量/单价/总价未知可空，部分金额不称总价，模板不推荐。
- [ ] 关系与业务类型分开，双方可搜索或手填当前单；税率/发票待补不阻断，结算不再重复。
- [ ] 新合同编号自动、历史原号可空，保留旧草稿内容；手机填写主页面完整可用。
