## 验收条件

- [ ] UI-16：独立档案页采用多维表格风格；按项目/合同/单据查找，查看及多选打包下载；关联原单、不重复上传，打包逐文件校验权限。
- [ ] UI-17：按项目、合同、单位名称和业务编号检索；结果和摘要均受现有单据可见权限约束。
- [ ] IAM-04：单据可见者可附件预览下载，不再输密码或查看原因；私有存储、后端授权和审计保持；无权单据不可由链接、搜索、导出或打包绕过。
- [ ] 所有有查看权人员可预览下载，后台每次鉴权短时链接和审计；水印保留。
- [ ] ZIP逐文件授权，搜索摘要无越权泄露；过期/旧轮文件链接不能绕过当前权限。
