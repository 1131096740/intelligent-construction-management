## 验收条件

- [ ] FND-15：关联出资人/原垫资，支持分次申请，按项目或公司日常岗位并联审批；通过后财务/综合主管实际支付，选任意我方公司资金或现金，不强制原入款来源。
- [ ] FND-16：剩余=原本金-有效已还-审批中及已批准未付占用；10万已还6仅余4，余4已有在途3只可再申1；驳回/撤回/核减释放；无利息/资金使用费功能。
- [ ] FND-17：资金账户待归还视图显示出资方或被代付公司、原额/已还/剩余/在途，直达申请；本金归还不计项目成本。
- [ ] 已付+全部有效未付占用不超本金，部分支付任务保留，任意公司/现金可按实际支付。
- [ ] 不计利息/成本/收入，账中待归还与历史归还来源可回看；重复申请/实付竞争拒绝。

- 业务片贯穿需要的Schema/约束、领域公开API、页面与真实行为测试；既有层无需改动时说明复用证据，不能为形式齐全改无关层。验证前置/技术验证/发布准备片以其可核验产物验收。
