## 验收条件

- [ ] OPS-11：业主结算100，施工转我方80，整体收入仍100；下游确认成本60、后付款不再加成本；主体间往来分别可看。
- [ ] OPS-12：施工付下游30+付我方50显示施工已付80；我方另付下游40，项目整体对外支付70，不把内部50再计。
- [ ] OPS-13：当前=已确认业主结算收入-已确认项目成本；资料不完整显示数据待补充并展示已知数，不将缺失当0或称最终利润；不做预计利润和利润分配。
- [ ] OPS-14：下游已结算未付可按合同钻取；审批中申请、已批准待付在未付中分列，不额外相加；不同合同预付和欠款不自动抵扣。
- [ ] OPS-15：业主已结算未收及预付款分别显示；对上合同显示施工企业应付我方并按公司查看，不再次计入整体收入。
- [ ] FND-22：公共现金支出计项目整体成本、来源公共现金；主体分账未明承担公司显示待归属；综合/财务发起原记录归属确认、财务主管确认，仅改归属，不再新增成本或付款。
- [ ] FND-23：到账/付款/转入/转出/退款及余额变化用表格呈现，按项目/公司/日期/类型过滤、导出，逐笔直达原记录；财务/财务主管/综合主管/总经理/董事长看全局，项目经理只项目相关资金。
- [ ] 业主100收入、内部80不重复，施工直接30转50我方付40→施工已付80/项目对外70。
- [ ] 成本来源唯一键可追溯，确认归属只改分账不再加成本；不完整显示已知与待补，不给伪最终利润。
- [ ] 应付的审批/待付只是组成部分不叠加，跨合同预付不自动冲抵，按公司分列施工应付我方。
