## 验收条件

- [ ] HIS-01：项目/名称/关系/甲乙双方、原约定金额及税务、可选清单和结算付款文本、历史累计结算、已签合同附件；多PDF/照片；框架无总价可空，不要求重录逐笔历史清单。
- [ ] HIS-02：取消历史合同A/B/C和等级调整说明；历史经营事实也用已确认/待核对，不让经办人选A/B/C；不能把原不确定资料自动升级为正式事实。
- [ ] HIS-03：合同部录入后推送财务及财务主管，任一有权人员可填/提，完成后其他待办结束；表内/表外填历史实际付款，对上填施工企业付我方的历史实际收款。
- [ ] HIS-04：合同部提交→财务填写→合同主管复核；财务看到项目/合同/关系/双方/金额或未约定/累计结算/附件摘要，约定可展开；主管再看财务金额，通过才入账。
- [ ] HIS-05：财务或主管均可填原因驳回制单人草稿，重提后财务重新核对再主管复核。历史接管步骤是职责接力，不套成所有人同一时间填同一数据。
- [ ] HIS-06：历史结算查不到保留合同部填写状态，无需额外操作；实付查不到保留财务状态；确实未发生才填0。
- [ ] HIS-07：已付70/结算60可实录并显示超付10；核实为约定预付款的显示未结算预付款10，性质不明待核对；对上超收保留事实，提示核对不自动退款。
- [ ] HIS-08：主管通过的历史合同可在结算工作台搜索新增，历史结算60+新10=70；历史已付并入合同后续余额，不重新生成历史实付。
- [ ] HIS-12：启用前历史合同实付/历史费用支付只参与历史事实和可付款核对，不再次扣启用时现金/公司资金期初；每条标清实际日期与期初涵盖范围。
- [ ] 无ABC，不问重复业务；未知保持原阶段无需虚填，真实0/超付/预付分别表达。
- [ ] 财务和主管驳回返合同制单，重提再经过财务；自审原因密码；简明摘要可展开合同附件。
- [ ] 历史60+新10累计70；历史已付不再扣账户期初，上传照片/PDF及电脑手机完整验证。
