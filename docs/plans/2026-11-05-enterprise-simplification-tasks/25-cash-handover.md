**状态：** `plan-confirmed` / `not-started`；前置工单未关闭，尚未实施。本轮用户已授权整套实施及 GitHub 工单推进；[#407](https://github.com/1131096740/intelligent-construction-management/issues/407) 已发布，归属父工单 [#382](https://github.com/1131096740/intelligent-construction-management/issues/382)。迁移、受控实验、部署与生产变更仍按各自具体授权执行。

**交付行为：** 现金保管变更记录交出与实点接收；旧保管人离职由财务发起，新保管人确认，差额待核对。

**Blocked by：** [24 公共现金与公司资金双向转款接力](24-cash-transfers.md)、[05 统一岗位配置、自审和委托权限](05-personnel.md)。

**技术决定：** [技术方案](../2026-11-05-enterprise-simplification-technical-plan.md) D06。**公开验收：** [验收情景](../2026-11-05-enterprise-simplification-acceptance.md) A22、A35。

## 验收条件

- [ ] FND-14：原人发起填写实际交付，新人确认；原人离职不能登录可财务发起；保留余额与历次收支；盘点差额待核对由财务查明更正，不自动抹平。
- [ ] 无自动调余额/自动费用收入；历史记录保留原办理人，当前权限转给新保管人。
- [ ] 交接确认与现金操作并发有版本保护，不能覆盖期间真实新收付。

## 验证与边界

- 业务片贯穿需要的Schema/约束、领域公开API、页面与真实行为测试；既有层无需改动时说明复用证据，不能为形式齐全改无关层。验证前置/技术验证/发布准备片以其可核验产物验收。
- 金额、权限、状态、文书、归档、审计用后端公开行为验证；最窄检查通过后做受影响包typecheck/lint，Web另做check:ui。依赖外部网关时明确模拟与真实边界。
- 保留真实数据及既有未提交内容；本票不包括无关清理、生产变更、重启/删除状态不明旧资源。受控实验/迁移/远程写须在实际实施时按项目既有授权流程处理。
- 完成时提供可复核行为、指纹/检查结果和未通过事项，更新简短进度；不能把旧SHA收据或文档确认作为本票通过。
