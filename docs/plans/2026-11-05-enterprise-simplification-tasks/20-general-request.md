## 验收条件

- [ ] PUR-02：办公用品、设备、软件、服务、礼品等综合需求，所有角色可申请；可选项目或公司日常，非项目不虚选项目。
- [ ] PUR-03：用多维表格列名称；规格、单位、数量、单价、预计总价、到位时间及说明可未知留空；已知照实填，不按0处理。
- [ ] PUR-04：项目零采两岗通过后通知项目物资员；综合采购通过后推送综合部，采购后由相应人员发起采购付款。
- [ ] PUR-05：两类均取消收货功能和付款前收货门槛；实际采购记录不是换名的收货或验收流程。
- [ ] PUR-06：申请预计10件实际12件、预计1000实际1200仅展示供核对，不因此自动阻止；实际付款仍走付款审批。
- [ ] 两类采购均清单名必填，数量单价总价/到位时间/采购说明未定可空；估价与实际不同不自动拦截。
- [ ] 从提交到采购待办不需收货，公开接口也无receipt前置；公司日常不假造项目。
