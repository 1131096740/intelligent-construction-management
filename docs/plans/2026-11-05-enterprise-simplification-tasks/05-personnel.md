## 验收条件

- [ ] IAM-01：人员与岗位入口配置姓名/手机号、公司级岗位和项目岗位，可兼岗多项目；审批流程页只看固定流程、人员和缺岗，不在线增删节点/顺序。
- [ ] IAM-02：物资主管可所有项目物资功能；合同主管可所有项目合同结算及复核；综合/财务主管可各自职责且看所有项目合同/结算/付款台账。
- [ ] IAM-03：可看所有项目合同/结算/付款台账和相关附件；财务与综合主管按权限办理实付；项目经理只负责项目，普通员工只本人发起/参与，不因同项目自动看他人敏感单据。
- [ ] IAM-05：停用不能登录/办理，历史单据/签字/付款保留；原人未办理职责可由新岗位人员继续；技术管理员自身不成为业务审批人。
- [ ] IAM-13：保留日志入口，普通人员在原单看相关记录；日志只显示有权信息，不等于授予业务批准权。
- [ ] APR-04：创建人或提交人之一确认自己的单据时均需自审原因+本人密码；一人兼多个节点逐节点自审，不因兼岗跳节点。
- [ ] APR-12：选被委托人及有效期，原人和受托人均可处理，一人处理后另一个对应待办结束；记录实办人及委托，不给受托人无关权限。
- [ ] 兼岗逐职责动作，委托先办者关闭对方职责待办；失效/停用即时撤权，旧链接不能继续办理。
- [ ] 普通财务、主管、项目经理、普通员工和技术admin建立读取/办理权限矩阵；有权查看流程者可按规则催办，查看权不等于审批/修改权。
- [ ] 实际变更和访问记录可由指定岗位查审计，系统管理员不得自动补成业务审批人。
