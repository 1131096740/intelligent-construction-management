# 24：公共现金与公司资金双向转款接力

**状态：** `plan-confirmed` / `not-started`；前置工单未关闭，尚未实施。本轮用户已授权整套实施及 GitHub 工单推进；[#406](https://github.com/1131096740/intelligent-construction-management/issues/406) 已发布，归属父工单 [#382](https://github.com/1131096740/intelligent-construction-management/issues/382)。迁移、受控实验、部署与生产变更仍按各自具体授权执行。

**类型：** 业务垂直片。目标为一个新会话可完成的边界；如果探索发现仍跨越多个独立用户路径，应先收窄票据再执行。

**交付行为：** 综合主管登记现金转公司，财务确认实际到账；公司转现金由保管人确认，两边不同时可用。

**Blocked by：** [15 公司登记余额与公共现金期初闭环](15-fund-accounts.md)、[16 财务与综合主管共办实付及资金提交安全](16-payment-execution.md)。

**需求：** FND-09、FND-10、FND-11。以[完整规格](../../specs/2026-11-05-enterprise-simplification-spec.md)最终规则为准，不能只实现票据标题。

**技术决定：** [技术方案](../2026-11-05-enterprise-simplification-technical-plan.md) D06。**公开验收：** [验收情景](../2026-11-05-enterprise-simplification-acceptance.md) A21、A22。

## 验收条件

- [ ] FND-09：转公司登记后金额锁为转款待确认不可重复用；财务确认实际到账后入公司资金；转移不记收入/成本。
- [ ] FND-10：财务驳回返原经办修改，保持待核对；仅确认现金实际退回或重提确认到账后更新，不能因驳回自动恢复可用现金。
- [ ] FND-11：交付款者登记，公司转出；综合部主管确认收现；两端同一转款事实，不重复计项目成本或收入，未确认资金不两边同时可用。
- [ ] 待转预占、确认实收、拒绝待核对、真实退回分开；拒绝不自动增加现金。
- [ ] 并发转款/付款守恒，单次确认幂等，来源/项目归属链不丢失。
