# 基础资料维护发布说明

Issue #318。用户授权统一综合部主管和董事长维护合作单位、我方公司、项目及项目关联公司，并在测试后直接上线；空项目可停用恢复，有业务项目沿用结项。本轮不改业务审批分工、不删除真实资料，不含综合采购新流程或短信启用。

1. 独立候选完成角色正反例、真实 PostgreSQL 16 事务与并发、桌面和手机入口验收；保留所有失败原件。固定提交后沿原本地完整17门、双轴审查、候选CI和合并CI交付。
2. 本轮没有 Schema 迁移；现有173项迁移保持。生产发布前读取当前版本、健康与备份状态，使用原 Deploy Production full/manual 和同SHA真实本地收据。由原脚本执行发布备份及校验，不手工伪造或拼接收据。
3. 发布后只读核对API/Web版本、三路健康、173项迁移、读写冻结恢复、备份三件套及异地回执；核对现有账号和资料未被创建测试业务。浏览器检查三个维护入口和权限提示，不代用户新增、停用真实公司或项目。
4. 失败按原发布脚本处理与恢复到已验收版本，保留全部业务数据。自然备份仍由既有只读任务验收，人工发布备份不充作自然计划执行成功。

操作说明见 [基础资料维护操作单](../guides/2026-10-15-master-data-maintenance.md)。最终运行SHA、CI、发布、生产证据在发布后写入当前进度及本轮执行收据。
