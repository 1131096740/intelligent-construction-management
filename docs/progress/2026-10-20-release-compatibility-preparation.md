## 发现与修复

- 非 owner PG16 测试复现银行核验签发函数的 PUBLIC EXECUTE：运行角色和备份角色都可调用。新增向前 ACL 迁移撤销 PUBLIC，单独 owner 部署授权步骤只向既有受限经营账 runtime 精确授权，不修改已应用迁移、函数正文或备份预检。
- 同一测试发现既有银行观察触发器要求 `assert_fund_execution_server_context`，服务还调用 `authorizeOperatingLedgerWrite`；恢复的生产 ACL 对 runtime 均无执行权。将这两个受密钥/事务上下文保护的入口纳入精确授权。备份角色仍不获得这些入口。
- 生产原已撤销旧资金写上下文守卫的 PUBLIC EXECUTE，而全新空库迁移尚未收紧；本次向前迁移固化同一边界，保持 runtime 的原有执行能力及触发器行为。
- 综合采购及项目花名册 DTO 不再假定项目 ID 为 UUID，改为有长度上限的非空字符串；数据库原主键不变，存在性、启用状态、项目归属及岗位检查仍由业务事务判定。其他对象和幂等键的 UUID 约束保留。
