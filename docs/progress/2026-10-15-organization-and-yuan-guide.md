# 董事长组织管理操作单

登录建工智管，在左侧「系统配置」分组中点击「组织权限」。电脑上菜单在左边；手机先展开菜单。

| 要办的事 | 操作 |
| --- | --- |
| 新增人员和账号 | 点「新增人员和账号」，填手机号，选部门和初始岗位；项目岗位还需选项目。确认已把公司统一初始密码安全告知本人，输入你自己的当前登录密码，点「创建人员和账号」。 |
| 员工首次登录 | 员工用自己的手机号和公司统一初始密码登录，按提示填写真实姓名并修改密码。创建时显示「待本人确认」是正常状态。 |
| 新增或调整部门 | 点「新增部门」，或在已有部门旁点「调整部门」，填名称、选择上级部门后保存。 |
| 调整人员所属部门 | 在该人员一行点「部门 / 停用」，选择新的所属部门，保持「是否启用」为「是」，输入自己的当前登录密码并保存。 |
| 调整岗位 | 在该人员一行点「新增岗位」或「撤销岗位」。先选择目标并查看影响，再用自己的当前登录密码确认。调岗可先给接替者授岗，再撤销原岗位。 |
| 停用离职人员 | 先撤销其岗位、完成系统提示的待办交接，再点「部门 / 停用」，将「是否启用」改为「否」并保存。人员不能再登录，原合同和审批记录继续保留。 |
| 重新启用人员 | 找到原人员，点「重新启用」，将「是否启用」改为「是」并保存，再按需要新增岗位。沿用原手机号账号。 |

所有确认密码都是操作者自己的当前登录密码。公司统一初始密码只通过安全渠道交给新员工；不要发到本对话。不要通过重复新建账号处理人员重新入职。

金额统一按「元」填写，最多两位小数。例如合同金额 12,345.67 元，填写 `12345.67`；一分钱填写 `0.01`。无需乘以 100。输入尚未完成时会提示修正，不会自动保存成旧金额。

首笔真实业务选定为新运粮河项目的历史材料合同：合同部补录原合同与已办完的累计结算，财务部按真实凭证补录每笔已付款，再由各自主管核对确认。未付余额继续保留；不要补成已付，也不要为了验收重新办理付款。自动备份由现有核验任务跟进。
