## 确认的问题及修复

1. 四类初始化共用手工占位 PDF（流长度错误、没有真实正文），且 re-seed 覆盖 V1。改用对应 DOCX、合成输入、正式渲染/转换链；已有版式跳过，冲突原文件拒绝覆盖，文件以独占方式写入。
2. 真实输入回归发现必填内容、材料运输费空清单、单价别名缺失及合计与大写不一致。仅修正初始化合成样张，不写历史合同事实；初始化和异步预览复用清单声明校验。
3. 原内置 DOCX 使用旧字体，真实 V2 检查拒绝。保持允许字体规则，在新副本中规范既知字体及选中框；预览副本补真实页码域，源资产和 V1 不变。Linux 真正可用字体下发现机械末尾空段挤出无正文页，仅压缩派生副本尾部空段，合同文字与签章表保留。正式合同文档生成规则不改。
4. 版式文件缺少资源授权，上传人以外的岗位即使能查看版式也不能读样张。增加精确版本/任务绑定，已发布 PDF 服从现有已发布列表权限，源文件/历史/草稿服从公司合同岗权限；任务过期、角色撤销、停用、指针变化和孤立资源拒绝，其他私有文件保持原规则。
5. 只读版式页、合同工作台补预览/下载，复用密码、原因、能力、短票据、审计、完整性保护。经领域 API 读取后展示 PDF/下载 Blob，避免票据相对路径绕过 `/api`。旧维护写入接口保持 410，不开放写入界面。
6. 缺下载人参数的公开票据请求曾触发 undefined.trim 500；现明确 400 拒绝且不读正文。
