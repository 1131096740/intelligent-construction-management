### 2. 干净 320 全量重放（阻断，已定位）

```bash
LINE_A_REQUIRE_CLEAN=1 ... pnpm verify:line-a-real-db:local   # 退出码 1
```

- 首次失败：`20261118221000_contract_legacy_guard_relation_namespace`。
  该迁移要求 `requireActiveProjectParticipatingCompany()` 的前态为 `ba713bc2…`；
  干净重放实际为 `9b3b12c7…`。差异来自生产在 2026-11-11 边界外置执行的
  `jg_install_direct_outside_operating_version_v2` / `..._assignment_lock_v2` 归档安装器；
  仓库内**没有任何迁移写入** `jg_contract_direct_upward_closure_v2` / 归档意图绑定，
  这些行只由 `.github/task12-install-295` 一次性安装器产生。
- 新增 `services/api/prisma/line-a-replay-archive-install-shim.sql`：仅精确复现上述安装器的
  **三个**前后态变换（`c376…→b448…`、`9b3b…→ba71…`、`a838…→e651…`），任何其他前态即拒绝。
  应用后重放推进到 `20261118223000_contract_normal_generated_archive_assignment_lock`，
  其安装前置检查要求真实 `jg_contract_direct_upward_closure_v2` 行（`< >1` 时抛
  `NORMAL_ARCHIVE_ASSIGNMENT_INSTALL_SCOPE`）；伪造该行会使
  `jg_require_contract_direct_upward_source_v2()` 的 `INTO STRICT` 失败，故停止，不伪造。
- 候选迁移 `20261119004200_signed_settlement_file_archive_manifest` 同样要求该归档安装前置
  （`SIGNED_SETTLEMENT_FILE_TRIGGER_INSTALL_SCOPE`），因此候选验证按显式清单跳过该迁移并记录；
  本票 4 条业务链不依赖它的归档文件清单触发器（`SignedContractSettlementAttachment` 走
  FileObject 原件链，04100/04900/05200/05300 已全部应用）。
