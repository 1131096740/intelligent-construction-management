# 模板取消操作的浏览器验收补强

关联 #333；基线 `5f5dbe4e4063c6df1c623344aaa67ae4b4e838c0`。

主线 CI `38928088461` 的手机结算模板场景在取消离开后，创建草稿按钮持续被对话框遮挡，原失败记录保留。原测试只检查提示出现及输入值保留，没有确认弹窗已完全展开或取消后已关闭。TDesign 初始对话框以透明、近零缩放的暂停动画进入，元素“可见”并不等同于按钮已展开。

仅修改该真实浏览器场景：按标题限定离开确认框，等待其不透明且不再缩放，再点击框内取消按钮，并断言确认框隐藏后才继续选择文件。原真实创建、丢失响应重试、幂等、权限、发布取消和冻结历史断言全部保留；不改业务实现、Schema、重试次数、超时或跳过项。

证据与限制：

- 未修改实现的原流程在 macOS 通过；macOS/Linux ARM64 WebKit 多轮取消和选择文件实验，以及受控延迟动画帧实验，均未稳定复现该 CI 单次失败。不能声称已证明唯一根因或完成产品缺陷的确定性红绿复现。
- 补强后的原 PostgreSQL 16 模板 HTTP 9 项及电脑/390px 手机全链通过；Linux ARM64 WebKit 的同一真实链也通过。Linux 浏览器来自一次性本机容器，后端及合成资料仍仅在本机；该结果不冒充 GitHub Linux x64 CI。临时探针和平台连接配置已移出候选。
- E2E 类型和目标 ESLint 通过。准确候选 CI、最终 main CI 与原完整发布门禁仍须通过；本记录不授权绕过失败，不是生产发布收据。
- 原基线的本地完整门另因 4215 端口被占用停止，属于独立环境失败；不与其他轮次拼接收据。
