# 合同版式初始化样张及只读访问整改

依据所有者 2026-10-20 明确授权，在隔离环境实施、验收并重新锁定发布版本。历史合同分类、金额和启用日期不补录；不迁移生产、不部署生产。

## 范围与不变量

- 四类：材料采购、设备租赁、劳务分包、通用合同。新初始化采用各自既有 DOCX、完整合成样张输入及正式 DOCX→PDF 转换器，禁止手工占位 PDF。合成样张应有真实正文、清单、双方及一致金额，标示样张/演示，不代表真实业务。
- 新生成的源副本将四份内置 DOCX 的既知旧字体替换为既有允许的 Noto Sans CJK SC，并将劳务源中的 Wingdings 选中框转成同义 Unicode 字符，压缩副本末尾不含正文、图形、域或分页内容的空段，避免无正文的末页；仅处理初始化/隔离新版本的派生副本，不改源资产或 V1。预览派生副本将原空页码栏换成 PAGE/NUMPAGES 域，不改正式合同渲染行为。
- 已有版式、原文件、V1、历史生成任务保持；重复初始化跳过已有版式，孤立冲突文件拒绝覆盖。替代样张须在隔离环境按既有领域服务的复制→检查→预览→提交→发布的新版本流程验收；旧维护 HTTP 入口保持退役，不恢复写入 UI。生产版本切换仍待所有者确认。
- 已发布 PDF 样张按现有认证用户的已发布版式列表查看范围授权；源 DOCX、草稿与历史版式沿用公司合同经办/主管的详情查看范围。技术管理员不自动获得维护或历史文件查看权。
- 文件授权必须绑定版本或有效样张任务，不能只凭上传人或全局岗位放开其他私有文件。旧任务、孤立任务不外泄。票据签发和实际读取均复核资源及当前权限。
- 版式只读详情及合同工作台提供明确的预览/下载入口，分别以 inline/attachment 返回；保留密码确认、原因、短期票据、完整性校验和审计。详情可显式查看历史已发布版本的原样张；不恢复模板写入界面。

## 验收与发布

- 正反权限、岗位撤销/停用、旧票据复核、无关私有文件隔离、预览/下载响应与审计、原件/V1保持、新版本完整生命周期。
- 四类实际 PDF 独立严格解析、中文正文和清单核验、逐页渲染，桌面/手机查看和下载字节完整性；检查双方、金额、页码、字体及分页。
- 双轴代码审查、全部 CI、准确最终合并 SHA 本机完整发布门及隔离迁移恢复重绑。确认包明确区分原件遗留问题与新样张验收结果，不复用旧 SHA 作为新发布资格。
- 原私有附件及原始证据仅保留本机私有目录，不提交、不上传；代码与公开合成验收资料可按既有授权提交、推送、PR，通过审查及 CI 后合并。
