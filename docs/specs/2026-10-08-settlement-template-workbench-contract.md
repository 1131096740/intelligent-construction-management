## 从当前代码确定的规则

- 维护岗位沿用`SettlementTemplateService`的全局`contract_director`、`super_admin`身份规则；不新增角色、不开放项目岗位代替全局身份。模板配置维护不授予合同、结算或付款审批权。
- 模板名称与编码必填且非空白；源文件必须为当前操作人拥有的有效私有XLSX；合同类型只接受已登记值；金额角色及计价模式只接受原枚举。
- 列、打印、证据及异常规则只接受原服务明确列出的安全配置，不扩大任意JSON。普通页面不显示原始JSON、内部文件编号或原始异常。
- 草稿修改要求精确`expectedRevision`，使已有检查/预览失效。检查须在当前修订；预览须有当前检查和真实XLSX/PDF产物。
- 提交仅允许草稿，且提交与发布都要求当前修订的检查通过、成功预览及真实XLSX/PDF产物；发布仅允许已提交版本，发布说明必填。原版本族锁、CAS、旧发布版本停止与审计保持同一事务。
- 原已提交/已发布内容不能覆盖；复制新版本沿用当前版本谱系规则。桌面与390px复用TDesign及`--jg-*`，新入口域API置于独立工作台路径，不能直接调用已退役写API。

## 字段适配边界

| 业务字段 | 当前领域权威 | 新页面表达 |
| --- | --- | --- |
| 模板名称、模板编码 | 原name/code必填校验 | 中文单行填写，仅创建时可编辑 |
| 模板源文件 | 原xlsxFileId及私有文件所有权/内容校验 | 受控上传与中文文件名，内部文件坐标不展示 |
| 兼容合同类型、金额角色、计价模式 | 原已登记类型及枚举、空数组表示全部 | 原中文多选项与说明 |
| 明细工作表 | 原columnSchema.sheetName，只接受本期结算明细 | 只读中文固定值 |
| 明细列 | 原columnSchema.columns必须为完整15列且顺序固定 | 只读固定列顺序，不提供子集或重排 |
| 必填列 | 原columnSchema.requiredColumns，只接受15个固定中文列 | 中文列选择；不开放任意列码或公式 |
| 证据必填列 | 原evidenceRules.requiredColumns，同一固定列集 | 中文列选择 |
| 打印区域检查 | 原printRules.requirePrintArea只能true或未显式设置 | 安全规则只读，不提供关闭控件 |
| 负向普通行、调整理由、公式、合并数据单元格检查 | 原anomalyRules对应4个键，只能true或未显式设置 | 安全规则只读，不提供关闭控件 |
| 发布说明 | 原changeSummary非空白规则 | 中文必填说明 |

源版本的未显式设置与显式true、未显式声明列与显式完整列数组，在原始快照中分别保留，不覆盖历史配置。规则对象由领域适配器
