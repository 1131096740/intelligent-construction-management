# 建工智管 - 数据库

当前版本采用 PostgreSQL 作为主数据库。旧版微信云数据库集合设计仅作为历史参考。

## 核心表

### 组织与权限

| 表 | 说明 |
| --- | --- |
| `users` | 用户账号、微信绑定、手机号 |
| `departments` | 部门 |
| `positions` | 岗位 |
| `user_positions` | 用户岗位，可支持一人多岗 |
| `projects` | 项目 |
| `project_members` | 项目成员和项目岗位 |
| `roles` | 系统角色 |
| `permissions` | 权限点 |

### 合同

| 表 | 说明 |
| --- | --- |
| `contracts` | 合同主档 |
| `contract_versions` | 合同版本，原合同、变更、补充协议 |
| `payment_terms_versions` | 付款条款版本 |
| `payment_terms_stages` | 多阶段付款条款 |
| `contract_archive_files` | 合同归档件 |

### 结算

| 表 | 说明 |
| --- | --- |
| `settlements` | 结算单 |
| `settlement_items` | 结算明细 |
| `settlement_archive_files` | 结算归档件 |

### 付款

| 表 | 说明 |
| --- | --- |
| `payment_requests` | 付款申请 |
| `payment_executions` | 实际付款记录，可分批付款 |
| `payment_vouchers` | 银行回单、付款凭证 |
| `finance_records` | 财务流水 |

### 审批

| 表 | 说明 |
| --- | --- |
| `approval_flows` | 审批流定义 |
| `approval_flow_nodes` | 审批节点定义 |
| `approval_instances` | 审批实例 |
| `approval_instance_nodes` | 实例节点 |
| `approval_actions` | 审批动作历史 |
| `approval_delegations` | 审批代理 |

### 文件、PDF、审计

| 表 | 说明 |
| --- | --- |
| `files` | COS 文件元数据 |
| `archives` | 资料库归档索引 |
| `pdf_documents` | 自动生成 PDF |
| `messages` | 站内消息 |
| `audit_logs` | 审计日志 |

## 关键关联

结算单必须绑定：

- `contract_id`
- `contract_version_id`
- `payment_terms_version_id`

付款申请必须绑定：

- `settlement_id`
- `contract_id`
- `contract_version_id`
- `payment_terms_version_id`

实际付款必须绑定：

- `payment_request_id`
- `settlement_id`

## 状态设计

合同版本状态：

- `draft`
- `in_approval`
- `approval_rejected`
- `approved_pending_seal`
- `in_seal`
- `seal_approved_pending_archive`
- `pending_archive_confirm`
- `effective`
- `voided`

结算状态：

- `draft`
- `in_approval`
- `approval_rejected`
- `approved_pending_archive`
- `pending_archive_confirm`
- `effective`
- `partially_paid`
- `paid`
- `voided`

付款状态：

- `draft`
- `in_approval`
- `approval_rejected`
- `approved_pending_payment`
- `partially_paid`
- `paid`
- `voided`

## 金额控制

付款申请金额必须满足：

```text
本次申请金额
  ≤ 结算单可付金额
    - 已审批待付款金额
    - 已实际付款金额
```

该校验必须在后端事务中完成。
