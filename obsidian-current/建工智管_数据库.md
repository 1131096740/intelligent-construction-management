# 建工智管 - 数据库

当前版本采用 PostgreSQL + Prisma。旧版微信云数据库集合设计仅作为历史参考。

同步时间：2026-07-15。当前 `services/api/prisma/schema.prisma` 共 70 个 Prisma model、50 个迁移。模型已覆盖组织权限、合同工作台、历史合同接管/批次/更正、项目经营、结算明细与模板、合同级付款、实付分摊/抵扣台账和项目支出。

## 关键关联

结算单必须绑定：

- `contract_id`
- `contract_version_id`
- `payment_terms_version_id`

付款申请必须绑定：

- `settlement_id`
- `contract_id`
- `contract_version_id`
- `payment_terms_version_id`

实际付款必须绑定：

- `payment_request_id`
- `settlement_id`

合同生成文档、线下修订稿、清单、合作单位快照都必须绑定到明确的合同版本，避免历史单据被后续模板或条款修改影响。

## 金额控制

付款申请金额必须满足：

```text
本次申请金额
  ≤ 结算单可付金额
    - 已审批待付款金额
    - 已实际付款金额
```

该校验必须在后端事务中完成。API 响应中的 BigInt 金额字段已统一 JSON 序列化为十进制字符串，避免生产返回 500。

数据库当前有一批以 `NOT VALID` 建立、用于先保护新增写入的约束；迁移中尚未找到统一的 `VALIDATE CONSTRAINT`。正式扩大使用前，应先对历史数据做只读一致性检查，再通过独立、可回滚的受控迁移完成验证，不能直接机械修改历史迁移。
