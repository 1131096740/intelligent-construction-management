# 建工智管 - 审批流

当前第一阶段只建设审批与合同付款闭环相关流程。其他完整方案中的审批类型后续阶段建设。

同步时间：2026-07-16。当前代码已覆盖合同、结算、付款三类审批的冻结实例、会签、或签、撤回、催办、转审、委托、驳回上一节点、打回申请人和审计留痕；综合费用已进入最小项目费用付款审批闭环。自动化测试不能代替真实岗位 UAT，正式扩大使用前仍须验证 3-5 条长链路和跨项目权限。历史已签合同接管不重走合同审批和用章审批，只做补录、归档、历史余额初始化和业务确认。

## 第一阶段审批流

| 编号 | 审批流 | 是否进入第一阶段 | 说明 |
| --- | --- | --- | --- |
| 1 | 合同签订审批 | 是 | 合同部编制，最终到董事长/总经理或签 |
| 2 | 合同变更/补充协议审批 | 是 | 生成新合同版本 |
| 3 | 用章申请 | 是 | 合同审批通过后自动触发 |
| 4 | 结算审批 | 是 | 不经过董事长/总经理 |
| 5 | 付款审批 | 是 | 所有付款都需董事长/总经理或签 |
| 6 | 综合费用最小付款审批 | 是 | 差旅、招待、报销先作为项目综合费用进入申请、审批、待付、实付、凭证、审计闭环 |
| 7 | 完整 OA 报销审批 | 后续阶段 | 发票识别、行程明细、多人报销、预算科目等不纳入当前上线验收 |
| 8 | 借款申请 | 后续阶段 | 不纳入当前上线验收 |
| 9 | 备用金申请 | 后续阶段 | 不纳入当前上线验收 |
| 10 | 物资领料审批 | 后续阶段 | 与成本、材料核销联动 |
| 11 | 请假/考勤 | 后续阶段 | 与人事考勤模块联动 |
| 12 | 入职/离职/调岗 | 后续阶段 | 与组织权限变更联动 |

## 合同签订/变更审批

```text
合同部成员编制合同和付款条款
  → 董事长/总经理或签
  → 自动触发用章审批
  → 综合部主管
  → 项目经理
  → 用章通过
  → 合同部成员上传盖章归档件
  → 合同部主管确认归档
  → 合同版本生效
```

董事长和总经理节点为或签。

严格超过原始金额 10%，或无限额合同发生任意非零金额变化的重大合同变更，由合同部成员或合同部主管作为合同经办人发起，审批路线为“合同部主管 → 项目经理 → 财务主管 → 董事长/总经理或签”。预算部主管不作为强制审批节点，但预算角色和可选复核资格继续保留。

申请人普通自审规则保持不变：合同部主管本人发起时，不得自行完成合同部主管节点，应由另一名合格合同部主管处理。

合同生效后不允许直接修改原条款。合同条款变化必须走合同变更或补充协议审批，并生成新合同版本。

## 结算审批

结算审批不经过董事长/总经理。

物资类/机械类：

```text
合同部成员编制结算单
  → 物资员
  → 物资主管
  → 合同部主管
  → 项目经理
  → 财务总监
  → 合同部成员上传签章归档件
  → 合同部主管确认归档
  → 结算单生效
```

劳务/专业分包类：

```text
合同部成员编制结算单
  → 工长
  → 项目总工
  → 工程技术部
  → 合同部主管
  → 项目经理
  → 财务总监
  → 合同部成员上传签章归档件
  → 合同部主管确认归档
  → 结算单生效
```

未生效合同不能创建结算。未归档确认的结算不能发起付款。

结算成本控制节点由合同部主管单独审批。预算角色继续保留，但不再是结算固定审批链的强制节点。

## 付款审批

付款必须基于已生效结算单发起。

```text
付款申请
  → 项目经理
  → 财务总监
  → 董事长/总经理或签
  → 审批通过待付款
  → 出纳/财务人员实际付款
  → 上传付款凭证
  → 已付款或部分付款
```

付款审批通过不等于已付款。

同一结算单支持分批付款，系统必须控制累计申请和累计付款不超过合同条款允许额度。

## 综合费用最小付款审批

P0-7C 只把差旅、招待、报销作为项目综合费用纳入最小付款闭环，不等同于完整 OA 报销系统。

```text
经办人提交综合费用
  → 项目经理
  → 综合部主管
  → 财务总监
  → 董事长/总经理或签
  → 审批通过待付款
  → 出纳/财务人员实际付款
  → 上传凭证
  → 财务记录和审计
```

后续完整 OA 报销再补发票识别、行程明细、多人报销、借款冲销和预算科目树。

## 审批引擎规则

- 审批实例提交后固化流程。
- 支持会签和或签。
- 支持条件节点，例如合同额 ≥ 100 万。
- 支持转审。
- 支持审批代理。
- 支持撤回。
- 支持驳回到上一级。
- 支持打回发起者重来。
- 审批超时只催办，不自动通过、不自动升级。
- 所有审批动作写入审计日志。
