## 三、审批流（共 13 类）

### ① 合同签订审批流
```
合同部编制合同
  → 物资部主管/工程部主管
    → [合同额 ≥ 100 万 → 工程技术部审核]
      → 合同部主管 + 预算部主管（并行会签，两者均通过）
        → 项目经理
          → 财务总监
            → 董事长/总经理审批通过
              → 【自动触发用章审批流】（略过董事长/总经理节点）
                  发起人(系统) → 综合部主管 → 项目经理
              → 用章审批通过 → 盖章
                → 上传合同原件（扫描件/电子版）
                  → 推送成控部（合同部）、财务部留档
```
- 物资类合同：物资部主管签
- 机械/劳务/专业分包合同：工程部主管（项目总工）签
- 合同额 ≥ 100 万时插入工程技术部审核节点
- 成控部内部：**合同部主管 + 预算部主管 并行会签**
- 经营部不参与合同签订审批
- **合同变更（补充协议）走相同流程**

### ② 结算审批流（合同部编制）

**物资类/机械类结算**
```
数据来源：物资员（现场拍照抄表收货）
      ↓
合同部编制结算单/对账单
      ↓
签字流：物资员 → 物资主管
  → 合同部主管 + 预算部主管（并行会签）
    → 项目经理 → 财务总监 → 董事长/总经理
      → 签字后推送成控部、财务部留档
```

**劳务/专业分包类结算**
```
数据来源：工长（现场收方拍照）
      ↓
合同部编制结算单/对账单
      ↓
签字流：工长 → 项目总工 → 工程技术部审核
  → 合同部主管 + 预算部主管（并行会签）
    → 项目经理 → 财务总监 → 董事长/总经理
      → 签字后推送成控部、财务部留档
```

### ③ 报销审批流（金额分级）

| 金额           | 审批路径                                |
| ------------ | ----------------------------------- |
| < 500 元      | 经办人 → 综合部主管 → 项目经理 ✅                |
| 500 ~ 5000 元 | 经办人 → 综合部主管 → 项目经理 → 财务总监 ✅         |
| > 5000 元     | 经办人 → 综合部主管 → 项目经理 → 财务总监 → 董事长/总经理 |

### ④ 付款审批流（以结算为依据）
```
经办人（物资部/工程部/项目经理）→ 项目经理 → 财务总监 → 董事长/总经理
```
- **前置条件**：必须有结算单
- 无结算无法发起
- **月度资金计划提示**：发起付款时显示该项目当月已用额度/剩余额度（仅提示，不阻止提交）资金计划源为上游预算收款

### ⑤ 零星材料支付审批流（金额分级）
```
发起人：物资员/物资主管
适用于：无合同的临时采购

< 3000 元/天：
  → 不走零星材料采购审批
  → 若使用备用金购买 → 事后走报销审批流（审批流③）
  → 若无备用金需公司直接支付 → 走付款审批流（审批流④）
  → 系统内需记账留痕

3000 ~ 10000 元：
  → 物资主管审批 → 项目经理 → 财务总监

> 10000 元：
  → 物资主管 → 项目经理 → 财务总监 → 董事长/总经理

完成后须附增值税发票（专票或普票）给财务部记账
```

### ⑥ 物资领料审批流
```
发起人：工长（工程部工长发起领料申请）
签字流：工长 → 项目经理 → 物资员发料登记
```
- 领料记录对接材料核销和成本控制

### ⑦ 借款申请
```
发起人 → 综合部主管 → 财务总监 → 董事长/总经理
```

### ⑧ 用章申请
```
发起人 → 综合部主管 → 项目经理 → [重要章 → 董事长/总经理]
```
**印章分类**：
| 类别 | 印章 | 审批终点 |
|------|------|----------|
| 重要章 | 合同章、公章、法人章 | 董事长/总经理 |
| 一般章 | 财务章、发票章、其他 | 项目经理 |

### ⑨ 请假/考勤（天数分级）

| 天数    | 审批路径                                |
| ----- | ----------------------------------- |
| ≤ 3 天 | 发起人（部员） → 部门负责人（结束）→综合部（归档）         |
| > 3 天 | 发起人（部员） →  部门负责人 → 项目经理（结束）→综合部（归档） |
|       | 发起人（部长） →项目经理→ 董事长/总经理（结束）→综合部（归档）  |

### ⑩ 入职/离职/调岗（项目人员）
```
综合部主管  → 人事主管 → 董事长/总经理
```

### ⑪ 入职/离职/调岗（公司人员）
```
人事专员 → 人事主管 → 董事长/总经理
```

### ⑫ 合同变更（补充协议）
→ 走与合同签订相同的审批流程（审批流 ①）

### ⑬ 备用金申请

**类型一：综合部备用金**
```
申请人：综合部部员
用途：项目部后勤、车辆、食堂、办公及其他开支
额度：每次 ≤ 5,000 元
审批流：综合部主管 → 项目经理 → 财务总监
```

**类型二：物资部备用金**
```
申请人：材料员（物资员）
用途：用于购买零星材料
审批流：物资部主管 → 项目经理 → 财务总监
```

> 备用金与借款申请的区别：备用金是小额日常预支（≤5,000元），借款申请是较大金额的正式借款。

## 四、审批流核心规则

| 规则          | 说明                                                    |
| ----------- | ----------------------------------------------------- |
| 条件金额（合同）    | ≥ 100 万合同额触发工程技术部审核节点                                 |
| 并行会签（成控部）   | 合同部主管 + 预算部主管两者均通过才流转到下一步                             |
| 金额分级        | 报销（<500/500-5000/>5000）、零星材料（<3000/3000-10000/>10000） |
| 天数分级        | 请假（≤3天 / >3天）                                         |
| 会签 / 或签     | 同节点多人时可设为全部通过（会签）或任一通过（或签）                            |
| 转审          | 审批人可转审给同部门/同项目其他人员                                    |
| **审批委托/代理** | 出差或请假时可提前设代理审批人，代理人代为处理审批                             |
| 催办          | 超过时限自动提醒（需消息通知系统支撑）                                   |
| **审批超时**    | 审批人超过 N 天不处理，仅催办（不自动升级/不自动通过）                         |
| **驳回**      | 审批人驳回后可选：驳回到上一级 或 打回发起者重来。必填驳回理由                      |
| **撤回**      | 发起人在审批人处理前可以撤回申请                                      |
| 付款前置条件      | 付款审批必须已有结算记录                                          |
| 零星材料后置条件    | 审批完成后必须补充发票                                           |
| **附件上传**    | 审批时必须上传附件（合同扫描件、收货单等）；发票可后补，无发票须备注                    |
| 盖章/签字后推送    | 合同盖章完成、结算签字完成后，自动推送成控部、财务部留档                          |
| 合同用章联动      | 合同签订审批最终通过后自动触发用章审批子流程                                |
| 印章分类        | 合同章/公章/法人章=重要章（到董事长/总经理），其他=一般章（到项目经理）                |
| 月度资金计划      | 付款审批时显示该项目当月已用/剩余额度（仅提示不阻止）                           |

| 维度 | 规则 |
|------|------|
| **项目隔离** | 项目层面角色只能看自己所属项目的数据 |
| **模块隔离** | 每个角色只能看与自己职能相关的模块 |

## 七、电子签名与审批单生成

### 电子签名功能
| 环节 | 说明 |
|------|------|
| **首次使用** | 全屏模式手写签名（Canvas 签字板），签名存入个人档案 |
| **后续审批** | 审批通过时自动将签名印在审批单对应位置 |
| **修改** | 随时可在"我的"页面重新签名 |
| **存储** | 签名图片存入云存储，关联用户 openid |

### 驳回机制
| 操作 | 说明 |
|------|------|
| **驳回到上一级** | 退回到前一审批人重新审核 |
| **打回发起者重来** | 退回到申请人修改后重新提交整个流程 |
| **驳回理由** | 必填，记录在审批历史中 |

### 审批单自动生成
| 环节 | 说明 |
|------|------|
| **触发时机** | 审批流程全部通过后自动生成 |
| **输出格式** | PDF 电子版留档（无需打印） |
| **内容** | 按模板格式填充表单数据 + 各级审批人签名 + 时间戳 + 审批意见 |
| **留档** | 合同盖章后/结算签字后推送成控部、财务部 |

## 八、各部门核心职责

### 成控部
**预算部职责**：工程预算编制、成本控制、目标成本制定、进度款审核、进度款报批
**合同部职责**：合同编制、结算编制、合同台账管理

### 财务部
收款与付款、报销与记账、合同结算审核、工资发放
审批流统一由 **财务总监** 签批。

### 物资部
采购管理、入库与领料、机械台班记录、供应商管理、材料核销
物资需求发起：项目工程部工长 → 物资部联系供应商 → 物资员现场收货拍照（附送货单、检验报告、合格证）

### 工程部（项目上）
现场收方、施工日志、安全管理、质量检查、进度管理（项目总工）、技术方案（项目总工）、发起物资需求

### 工程技术部（公司层面）
审批施组/技术方案/进度计划、过程重点难点指导、组织竣工图、汇报进度产值
合同额 ≥ 100 万时审核合同、审核劳务/专业分包最终结算

### 经营部（公司层面）
招投标、市场开拓、对上游甲方合同谈判（线下）
**不参与** 合同签订审批、付款审批

### 人事部（公司层面）
公司行政及人事管理、五险一金、证书管理、员工入离职/调岗审批

### 综合部（项目层面）
水电/房租/网络、餐饮住宿、报销办公用品、请假/考勤、用章管理、项目杂事
