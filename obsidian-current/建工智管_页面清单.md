# 建工智管 - 页面清单

当前版本以 Web 管理端为主系统；微信小程序端是移动工作端，`apps/miniprogram` 已建立最小骨架但仍待真机和生产账号验收。

同步时间：2026-07-09。下表分为“已实现/已接入”和“规划/待建设”，避免把设计范围误读为当前完成状态。

前端 UI 口径：Web 管理端统一使用 TDesign Web；当前页面已经形成企业后台方向，`apps/web-admin/src/app/design-tokens.css` 已作为薄 token 层接入，但合同工作台、模板中心和历史页面仍有原生控件与散落样式，后续按前端改造方案逐步收口。

## 设计原则

- Web 负责复杂配置和台账管理。
- 小程序负责移动审批、签名、附件查看和上传。
- 同一单据在双端显示同一编号、状态、流程和权限。
- 小程序不承载复杂付款条款配置和审批流配置。
- 试运行期 Web 优先跑真实项目、历史合同接管、付款/结算/综合费用闭环和问题台账，小程序后置。
