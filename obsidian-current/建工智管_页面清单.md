# 建工智管 - 页面清单

当前版本包含 Web 管理端和微信小程序端。Web 是主系统，小程序是移动工作端。

## Web 管理端

| 模块 | 页面 | 说明 |
| --- | --- | --- |
| 工作台 | 企业工作台 | 待办、预警、待归档、待付款 |
| 组织权限 | 员工管理 | 人员、岗位、部门、项目授权 |
| 组织权限 | 角色权限 | 角色、岗位、菜单、数据范围 |
| 项目 | 项目台账 | 项目信息、成员、合同入口 |
| 合同 | 合同台账 | 合同列表、状态、版本、金额 |
| 合同 | 合同详情 | 版本时间轴、付款条款、审批、归档件 |
| 合同 | 付款条款编辑 | 多阶段付款规则、原文条款 |
| 合同 | 合同审批详情 | 流程、附件、意见、签名 |
| 用章 | 用章待办 | 合同自动触发用章 |
| 归档 | 合同归档确认 | 上传件查看、确认或退回 |
| 结算 | 结算台账 | 月度/节点结算、状态、金额 |
| 结算 | 结算详情 | 合同版本、条款版本、付款进度 |
| 归档 | 结算归档确认 | 签章结算单确认 |
| 付款 | 付款申请 | 从已生效结算发起 |
| 付款 | 待付款列表 | 审批通过待付款 |
| 付款 | 实际付款登记 | 出纳登记付款、上传凭证 |
| 资料库 | 资料库 | 合同、结算、付款、PDF 留档 |
| 审计 | 审计日志 | 登录、审批、归档、下载、付款 |
| 系统 | 审批流配置 | 流程节点、会签/或签、条件 |
| 系统 | 安全与备份 | 基础配置和运行诊断 |

## 微信小程序端

| Tab | 页面 | 说明 |
| --- | --- | --- |
| 工作台 | 移动工作台 | 待我审批、消息、快捷入口 |
| 审批 | 审批列表 | 待我审批、我发起、已处理 |
| 审批 | 审批详情 | 查看附件、意见、流程、处理 |
| 附件 | 上传附件 | 拍照、文件、签名 |
| 消息 | 消息中心 | 审批、催办、归档提醒 |
| 我的 | 个人中心 | 员工绑定、签名、账号信息 |

## 设计原则

- Web 负责复杂配置和台账管理。
- 小程序负责移动审批、签名、附件查看和上传。
- 同一单据在双端显示同一编号、状态、流程和权限。
- 小程序不承载复杂付款条款配置和审批流配置。
