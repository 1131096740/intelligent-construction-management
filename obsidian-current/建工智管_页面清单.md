# 建工智管 - 页面清单

当前版本以 Web 管理端为主系统；微信小程序端是移动工作端，但 `apps/miniprogram` 尚未建立。

同步时间：2026-07-01。下表分为“已实现/已接入”和“规划/待建设”，避免把设计范围误读为当前完成状态。

| 模板中心 | 版式模板 | DOCX 版式模板、占位符检查、预览 |

## 设计原则

- Web 负责复杂配置和台账管理。
- 小程序负责移动审批、签名、附件查看和上传。
- 同一单据在双端显示同一编号、状态、流程和权限。
- 小程序不承载复杂付款条款配置和审批流配置。
