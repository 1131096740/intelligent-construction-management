## 重要安全提醒

- 当前本地 seed/test 数据仍可能使用通用密码 `Jgzg@2026`。强制改密已上线并已有 2 名员工完成，剩余真实账号仍需继续完成个人改密、seed 通用密码停用和 token 撤销验收。
- DNSPod API Token 仅保存在生产服务器 `/etc/jiangkong/dnspod.env`，权限为 root 600。不得提交到仓库、截图、外传或写入客户端；如果发生暴露，必须立即在 DNSPod 吊销并重建。
- 当前证书自动续期已接入 DNSPod API，但仍应在 2026-09-29 到期日前观察一次自动续期日志，确认定时任务真实跑通。
- 当前 Web 鉴权 token 仍由前端持久化管理。正式公网域名开放前，建议单独做 `HttpOnly; Secure; SameSite=Lax` Cookie 化专项；至少先完成 XSS 风险复查和退出 / 改密后的 token 撤销验收。
- 登录和刷新接口正式试运行前需要限流。最小做法可以先落在 Nginx `limit_req`，后续再收进 Nest 中间件或 Guard。

## MVP 验收重点

- 合同未生效不能结算。
- 结算未生效不能付款。
- 付款审批通过后仍为待付款。
- 实际付款必须由财务人员登记并上传凭证。
- 同一结算支持分批付款。
- 历史单据可追溯合同版本和付款条款版本。
- 历史合同接管后的历史余额可扣减后续付款容量。
- 敏感文件不可公开访问。
- 关键操作均有审计日志。
