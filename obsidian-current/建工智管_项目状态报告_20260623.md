## 一、项目定位

建工智管是一个**建筑企业项目经营管理系统**，不是简单的微信小程序。当前是第一阶段 MVP，主线是实现「合同 → 结算 → 付款」的完整审批闭环。

系统由三个部分组成：

| 端 | 定位 | 技术栈 |
|---|---|---|
| **Web 管理端** | 企业主系统，负责台账管理、复杂配置 | Vue 3 + TypeScript + TDesign |
| **微信小程序端** | 移动工作端，负责审批、签名、附件 | 原生微信小程序（未开始） |
| **统一后端** | 业务规则、权限、审批、文件中枢 | NestJS + PostgreSQL + Prisma |
