# 建工智管 - 总览

建工智管是建筑企业项目经营管理系统，不是单纯微信小程序。

## 当前版本定位

当前版本为第一阶段 MVP，主线是 **审批与合同付款闭环**。

系统由三部分组成：

- Web 管理端：企业主系统。
- 微信小程序端：移动工作端。
- 统一后端：业务规则、权限、审批、文件、PDF、审计中枢。

## 第一阶段主线

```text
合同编制
  → 合同付款条款录入
    → 合同审批
      → 用章审批
        → 合同归档确认
          → 合同生效
            → 结算审批
              → 结算归档确认
                → 结算生效
                  → 付款申请
                    → 付款审批
                      → 待付款
                        → 实际付款登记
                          → 财务流水、PDF、审计
```

## 技术架构

| 端 | 技术 |
| --- | --- |
| Web 管理端 | Vue 3 + TypeScript + TDesign Web + Vite |
| 小程序端 | 原生微信小程序 + TDesign 小程序 |
| 后端 | Node.js + NestJS + PostgreSQL |
| 文件 | 腾讯云 COS 私有桶 |
| 部署 | 腾讯云轻量应用服务器 |

## 核心原则

- Web 是主系统，小程序是移动工作端。
- 所有业务规则在后端执行。
- 合同、结算、付款必须强顺序绑定。
- 合同和结算必须上传归档件并确认后才生效。
- 付款审批通过不等于已付款。
- 合同付款条款版本化，历史结算和付款按当时版本追溯。
- 不做固定 IP 白名单，采用强身份、强权限、私有文件、全审计。
