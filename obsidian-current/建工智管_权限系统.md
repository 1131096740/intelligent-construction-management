# 建工智管 - 权限系统

当前版本按企业级角色、项目、部门、单据关系进行权限控制。旧版 8 角色模型不再作为当前依据。

同步时间：2026-07-15。当前后端写端点已接登录态、JWT、项目可见性和岗位权限 Guard；操作人从 token 获取，不再信任请求体中的用户 ID。组织权限管理、角色影响预览、委托有效期、文件下载、归档确认、历史接管确认、实际付款等敏感动作已有后端校验和审计。上线试运行重点转为用普通岗位账号复验跨项目读取、历史接管、费用、下载、实付和人员岗位管理边界。

## 权限原则

- 项目角色默认只能访问授权项目。
- 公司级审批角色按职责访问相关单据。
- 财务资料默认仅财务部、董事长、总经理可见。
- 项目经理可查看本项目付款状态，但默认不能查看银行回单。
- 文件下载必须由后端鉴权、当前密码二次确认签票，并记录审计。
- 前端只做展示控制，后端必须强制校验权限。

## 敏感操作

以下操作已接入当前密码二次确认并写审计：

- 合同归档确认。
- 结算归档确认。
- 历史合同接管确认。
- 实际付款登记。
- 敏感文件下载。

以下操作仍需按上线策略补齐或确认是否强制二次确认：

- 历史余额更正。
- 付款最终审批。
- 上传或替换付款凭证。
- 权限变更。
- 单据作废。
- 合同模板发布/停用/撤回。
- 生产数据初始化和种子账号密码重置。

## 登录策略

- Web：手机号 + 密码登录，JWT access/refresh，会话刷新与改密已接入。
- 移动端目标：手机浏览器使用与桌面相同的 Web 登录、权限和后端 API；小程序登录入口等待按退出计划清理，不再安排绑定或真机验收。
- 不做固定 IP 白名单。
- 预留设备管理、强制下线、异常登录提醒。

当前 Web 的 access/refresh token 仍保存在 `localStorage`，公网尚未配置 CSP。这不影响权限规则本身，但会放大潜在 XSS 的影响，应作为独立认证安全专项评估，不能在文档中写成已经完成。

## 上线前权限验收

- 用真实岗位账号逐一验证合同新建、历史合同接管、结算审批、付款审批、综合费用申请、实际付款、凭证上传、文件下载和审计查询。
- 确认财务可读取业务归档文件但不负责上传合同/结算归档件。
- 确认项目经理可查看本项目付款状态，但银行回单/敏感财务资料按财务权限控制。
- 停用或修改所有 seed 通用密码，生产账号必须按真实员工发放。
- 使用不同项目的普通账号验证列表、详情、附件下载和直接 URL 访问均不会跨项目泄露。
