# 建工智管 - 权限系统

当前版本按企业级角色、项目、部门、单据关系进行权限控制。旧版 8 角色模型不再作为当前依据。

## 第一阶段核心角色

| 角色 key | 中文名 | 权限范围 |
| --- | --- | --- |
| `chairman` | 董事长 | 合同最终审批、付款最终审批、全局查看 |
| `general_manager` | 总经理 | 合同最终审批、付款最终审批、全局查看 |
| `project_manager` | 项目经理 | 本项目合同、结算、付款审批与查看 |
| `contract_director` | 合同部主管 | 合同/结算审核、归档确认 |
| `contract_staff` | 合同部成员 | 合同编制、付款条款录入、归档件上传 |
| `budget_director` | 预算部主管 | 成控会签、金额和预算审核 |
| `budget_staff` | 预算部成员 | 成控资料协助 |
| `finance_director` | 财务总监 | 合同、结算、付款财务审批 |
| `finance_staff` | 财务人员/出纳 | 实际付款登记、付款凭证上传 |
| `material_director` | 物资主管 | 物资类合同/结算节点 |
| `material_staff` | 物资员 | 物资类结算证据节点 |
| `engineering_director` | 项目总工 | 劳务/专业分包合同和结算节点 |
| `engineering_foreman` | 工长 | 劳务/专业分包结算收方节点 |
| `engineering_tech` | 工程技术部 | 大额合同、劳务/专业分包结算审核 |
| `comprehensive_director` | 综合部主管 | 用章审批节点 |
| `employee` | 普通员工 | 本人数据和基础事项 |
| `super_admin` | 系统管理员 | 技术初始化与配置，不代表业务审批岗位 |

## 权限原则

- 项目角色默认只能访问授权项目。
- 公司级审批角色按职责访问相关单据。
- 财务资料默认仅财务部、董事长、总经理可见。
- 项目经理可查看本项目付款状态，但默认不能查看银行回单。
- 文件下载必须由后端鉴权并记录审计。
- 前端只做展示控制，后端必须强制校验权限。

## 敏感操作

以下操作需要二次确认并写审计：

- 合同归档确认。
- 结算归档确认。
- 付款最终审批。
- 实际付款登记。
- 上传或替换付款凭证。
- 权限变更。
- 单据作废。
- 敏感文件下载。

## 登录策略

- Web：账号登录，后续可加短信或二次验证。
- 小程序：微信登录 + 员工档案绑定。
- 不做固定 IP 白名单。
- 预留设备管理、强制下线、异常登录提醒。
