# 建工智管 - 后端模块清单

当前版本不再采用 41 个分散微信云函数作为主架构。

主后端采用 Node.js + NestJS + PostgreSQL。微信能力作为适配层。

## NestJS 模块

| 模块 | 说明 |
| --- | --- |
| `AuthModule` | Web 登录、小程序微信登录、员工绑定、会话 |
| `OrganizationModule` | 部门、岗位、人员 |
| `ProjectModule` | 项目、项目成员、项目授权 |
| `ContractModule` | 合同主档、合同版本、付款条款版本 |
| `ApprovalModule` | 审批流定义、审批实例、会签/或签、代理、催办 |
| `SealModule` | 用章申请、用章审批、用章结果 |
| `SettlementModule` | 结算单、结算审批、结算归档、生效 |
| `PaymentModule` | 付款申请、付款审批、实际付款、凭证 |
| `ArchiveModule` | 资料库、归档确认、文件权限 |
| `FileModule` | COS 私有文件上传、下载鉴权、临时链接 |
| `PdfModule` | 合同、结算、付款审批 PDF 生成 |
| `AuditModule` | 审计日志 |
| `NotificationModule` | 站内消息、微信订阅消息 |
| `SystemModule` | 运行诊断、配置、备份检查 |

## 微信适配能力

- 小程序登录。
- 微信 openid 绑定员工。
- 微信订阅消息。
- 小程序文件上传入口。

## 定时任务

- 审批超时催办。
- 合同到期提醒。
- 待付款到期提醒。
- 数据库备份检查。
- 审计日志归档检查。

## 关键后端原则

- 所有权限在后端校验。
- 所有金额变动在数据库事务中完成。
- 文件下载必须鉴权。
- 审批实例提交后固化流程。
- 历史结算和付款绑定当时的合同版本和付款条款版本。
